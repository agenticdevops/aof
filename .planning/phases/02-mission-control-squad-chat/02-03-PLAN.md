1. Create `src/hooks/useWebSocket.ts` custom hook:

   - Handle connection, disconnection, reconnection
   - Props/params: {
       url: string (e.g., 'ws://localhost:7777/ws'),
       onMessage: (event: WSEvent) => void,
       onError: (error: Error) => void,
       onConnect: () => void,
       onDisconnect: () => void
     }

2. Features:
   - Auto-connect on mount
   - Auto-reconnect on disconnect with exponential backoff:
     * Attempt 1: 3s delay
     * Attempt 2: 6s delay
     * Attempt 3: 12s delay
     * Attempt 4+: 30s delay (capped)
   - Connection status: 'connecting' | 'connected' | 'disconnected' | 'error'
   - Max reconnection attempts: 10 (then give up, user can retry)

3. Implementation:
   ```
   const useWebSocket = (url, { onMessage, onError, onConnect, onDisconnect }) => {
     const [status, setStatus] = useState('disconnected')
     const wsRef = useRef(null)
     const reconnectTimeoutRef = useRef(null)
     const reconnectAttemptsRef = useRef(0)

     useEffect(() => {
       connect()
       return () => {
         if (wsRef.current) wsRef.current.close()
         if (reconnectTimeoutRef.current) clearTimeout(reconnectTimeoutRef.current)
       }
     }, [])

     const connect = () => {
       try {
         const ws = new WebSocket(url)
         ws.onopen = () => {
           setStatus('connected')
           reconnectAttemptsRef.current = 0
           onConnect?.()
         }
         ws.onmessage = (e) => {
           const data = JSON.parse(e.data)
           onMessage?.(data.event)
         }
         ws.onerror = (e) => {
           setStatus('error')
           onError?.(new Error('WebSocket error'))
         }
         ws.onclose = () => {
           setStatus('disconnected')
           onDisconnect?.()
           scheduleReconnect()
         }
         wsRef.current = ws
       } catch (err) {
         onError?.(err)
         scheduleReconnect()
       }
     }

     const scheduleReconnect = () => {
       if (reconnectAttemptsRef.current >= 10) return
       const delay = Math.min(3000 * Math.pow(2, reconnectAttemptsRef.current), 30000)
       reconnectTimeoutRef.current = setTimeout(() => {
         reconnectAttemptsRef.current++
         setStatus('connecting')
         connect()
       }, delay)
     }

     return { status, ws: wsRef.current }
   }
   ```

4. Error handling:
   - Catch connection errors
   - Catch JSON parsing errors
   - Call onError callback for component/Redux to handle

5. TypeScript: Strict mode, full type safety
