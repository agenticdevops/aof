3. Create `web-app/src/types/fleet.ts` with string literal types (NOT enums):
   - `SquadHealthStatus = 'healthy' | 'degraded' | 'critical'`
   - `FilterRole = 'all' | 'orchestrator' | 'specialist' | 'analyst' | 'responder'`
   - `interface SquadMember { id: string; name: string; role: string; status: string; personaColor: string; personaIcon: string; uptime: number; successRate: number }`
   - `interface Squad { id: string; name: string; lead: SquadMember; members: SquadMember[]; health: SquadHealthStatus; memberCount: number }`
   - `interface FleetState { squads: Squad[]; agents: SquadMember[]; activeFilter: FilterRole; squadFilter: string | null; isLoading: boolean; error: string | null }`
   - `interface FleetAgent` — raw agent from /api/config/agents (id, name, role, coordinationWith, personality, personaColor, personaIcon, status, metrics)

4. Create `web-app/src/store/slices/fleetSlice.ts`:
   - `createAsyncThunk('fleet/fetchAgents')` — fetches from `/api/config/agents` and `/api/agents` in parallel, merges config + runtime data
   - `deriveSquads(agents: FleetAgent[]): Squad[]` — exported utility function:
     * Find agents with role 'orchestrator' or agents that appear in other agents' coordinationWith
     * Each coordinator/orchestrator becomes a squad lead
     * Squad members = agents whose coordinationWith includes the lead's id
     * Agents not in any squad become a "Unassigned" catch-all squad
     * Squad health = 'healthy' if all members active, 'degraded' if any idle, 'critical' if any error
   - Reducers: `setFilter(role)`, `setSquadFilter(squadId | null)`, `clearFilters()`
   - Selectors: `selectSquads`, `selectFilteredAgents` (memoized with createSelector), `selectActiveFilter`, `selectSquadFilter`, `selectFleetLoading`, `selectFleetError`
   - `selectFilteredAgents` should filter by role AND squad, returning the matching agents

5. Add `fleet: fleetReducer` to `web-app/src/store/store.ts` reducer map (import from `./slices/fleetSlice`)

6. Export fleet slice actions and thunks from `web-app/src/store/index.ts`:
   ```typescript
   // Fleet Slice exports
   export {
     setFilter,
     setSquadFilter,
     clearFilters,
     fetchFleetAgents,
   } from './slices/fleetSlice'
   ```
  </action>
