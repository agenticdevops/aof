1. Create `web-app/src/types/kanban.ts` with string literal types:
   - `KanbanLane = 'backlog' | 'assigned' | 'in-progress' | 'review' | 'done'`
   - `TaskPriority = 'low' | 'medium' | 'high' | 'critical'`
   - `TaskStatus = 'pending' | 'active' | 'completed'`
   - `interface Task { id: string; title: string; description: string; lane: KanbanLane; assignedTo: string | null; version: number; createdAt: string; updatedAt: string; status: TaskStatus; priority: TaskPriority | null; tags: string[] | null; dueDate: string | null }`
   - `interface CreateTaskPayload { title: string; description: string; lane?: KanbanLane; priority?: TaskPriority; tags?: string[]; assignedTo?: string }`
   - `interface MoveTaskPayload { taskId: string; newLane: KanbanLane; version: number }`
   - `interface KanbanState { tasks: Task[]; isLoading: boolean; error: string | null; selectedTask: Task | null; isCreateModalOpen: boolean }`
   - `KANBAN_LANES: readonly KanbanLane[]` — const array `['backlog', 'assigned', 'in-progress', 'review', 'done'] as const`
   - `LANE_LABELS: Record<KanbanLane, string>` — `{ backlog: 'Backlog', assigned: 'Assigned', 'in-progress': 'In Progress', review: 'Review', done: 'Done' }`

2. Create `web-app/src/store/slices/kanbanSlice.ts`:
   - `fetchTasks = createAsyncThunk('kanban/fetchTasks')` — GET /api/tasks, returns Task[]
   - `createTask = createAsyncThunk('kanban/createTask')` — POST /api/tasks with CreateTaskPayload, returns Task
   - `moveTask = createAsyncThunk('kanban/moveTask')` — POST /api/tasks/move with MoveTaskPayload
     * On success (200): return the updated task from response
     * On 409 conflict: return rejectWithValue({ conflict: true, task: response.data.task })
     * On other error: return rejectWithValue({ conflict: false, message: error.message })
   - Reducers:
     * `optimisticMove(state, { taskId, newLane })` — immediately update task.lane in state
     * `revertMove(state, task: Task)` — replace task with server version
     * `confirmMove(state, task: Task)` — update task with server response (incremented version)
     * `setSelectedTask(state, task: Task | null)` — for detail modal
     * `setCreateModalOpen(state, open: boolean)` — toggle create modal
   - extraReducers for thunk states (loading, fulfilled, rejected)
   - For moveTask.rejected: if conflict, dispatch revertMove; show toast via callback ref pattern
   - Selectors (memoized with createSelector):
     * `selectTasks` — all tasks
     * `selectTasksByLane(lane)` — tasks filtered by lane, factory selector pattern
     * `selectSelectedTask` — currently selected task
     * `selectKanbanLoading` — loading state
     * `selectIsCreateModalOpen` — create modal state

3. Add `kanban: kanbanReducer` to `web-app/src/store/store.ts` reducer map

4. Export kanban slice actions and thunks from `web-app/src/store/index.ts`:

   ```typescript
     confirmMove,

     setCreateModalOpen,
     fetchTasks,
     createTask,
     moveTask,
   } from './slices/kanbanSlice'
   ```

     * This keeps the Kanban board in sync across browser windows
