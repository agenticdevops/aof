<objective>
Build the visual workflow builder using React Flow for creating multi-agent DAG workflows.

Purpose: Users need to visually compose multi-agent workflows by dragging agents from a palette onto a canvas and connecting them with edges. This defines execution order for agent collaboration. The DAG editor is frontend-only (no backend workflow API yet) — workflows are stored in Redux and can be exported as JSON.

Output: WorkflowBuilder page at /workflow-builder with React Flow canvas, custom AgentNode, sidebar palette, dagre auto-layout, controls for save/clear/export, and navigation integration.
</objective>

1. Create `web-app/src/types/workflow.ts` with string literal types:
   - `interface AgentNodeData { agentId: string; name: string; role: string; personaColor: string; personaIcon: string }`
   - `interface WorkflowNode { id: string; type: 'agentNode'; position: { x: number; y: number }; data: AgentNodeData }`
   - `interface WorkflowEdge { id: string; source: string; target: string; animated?: boolean }`
   - `interface WorkflowMeta { id: string; name: string; description: string; createdAt: string; updatedAt: string }`
   - `interface WorkflowState { nodes: WorkflowNode[]; edges: WorkflowEdge[]; meta: WorkflowMeta; isDirty: boolean }`
   - `interface WorkflowExport { meta: WorkflowMeta; nodes: WorkflowNode[]; edges: WorkflowEdge[] }` — for JSON export

2. Create `web-app/src/store/slices/workflowSlice.ts`:
   - Initial state: empty nodes/edges, default meta (id: 'default', name: 'New Workflow', description: '', timestamps: now)
   - Reducers:
     * `addWorkflowNode(state, node: WorkflowNode)` — add to nodes array, set isDirty
     * `removeWorkflowNode(state, nodeId: string)` — remove node AND any edges connected to it
     * `updateNodePosition(state, { nodeId, position })` — update position on drag
     * `setNodes(state, nodes: WorkflowNode[])` — bulk set (for dagre layout result)
     * `addWorkflowEdge(state, edge: WorkflowEdge)` — add edge, set isDirty
     * `removeWorkflowEdge(state, edgeId: string)` — remove edge
     * `setEdges(state, edges: WorkflowEdge[])` — bulk set
     * `updateWorkflowMeta(state, { name?, description? })` — update meta fields + updatedAt
     * `clearWorkflow(state)` — reset to initial state
     * `loadWorkflow(state, { nodes, edges, meta })` — load from export JSON
   - Selectors: `selectWorkflowNodes`, `selectWorkflowEdges`, `selectWorkflowMeta`, `selectWorkflowIsDirty`

3. Create `getLayoutedElements` utility function (can be in workflowSlice or separate utils file):
   - Import `dagre` from `@dagrejs/dagre`
   - Takes `(nodes: WorkflowNode[], edges: WorkflowEdge[], direction = 'TB')`
   - Create dagre graph, set each node as 200x80, add edges
   - Run `dagre.layout(dagreGraph)`
   - Return nodes with updated positions (centered: x - 100, y - 40)
   - Export as `getLayoutedElements` for use by WorkflowControls

4. Add `workflow: workflowReducer` to `web-app/src/store/store.ts` reducer map

5. Export workflow slice actions from `web-app/src/store/index.ts`:
   ```typescript
   // Workflow Slice exports
   export {
     addWorkflowNode,
     removeWorkflowNode,
     updateNodePosition,
     setNodes as setWorkflowNodes,
     addWorkflowEdge,
     removeWorkflowEdge,
     setEdges as setWorkflowEdges,
     updateWorkflowMeta,
     clearWorkflow,
     loadWorkflow,
   } from './slices/workflowSlice'
   ```
  </action>

   - Import `nodeTypes` from `./AgentNode` (module-scope object)
   - Props: `{ className?: string }`
   - Read nodes/edges from Redux via selectors
   - Use `useNodesState` and `useEdgesState` initialized from Redux state
   - Sync local React Flow state back to Redux:
     * `onNodesChange` → update local state (React Flow manages drag positions internally)
     * `onConnect` → `addEdge` to local edges + dispatch `addWorkflowEdge` to Redux
     * `onNodeDragStop` → dispatch `updateNodePosition` to Redux (sync after drag completes)
   - `onDrop` handler: accept drops from sidebar palette (read agentId/name/role from dataTransfer)
     * Create new WorkflowNode at drop position (use `reactFlowInstance.screenToFlowPosition`)
     * Dispatch `addWorkflowNode`
   - `onDragOver` handler: `event.preventDefault()` + `event.dataTransfer.dropEffect = 'move'`
   - Get `reactFlowInstance` via `onInit` callback (store in ref)
   - Dark mode: `colorMode={theme === 'dark' ? 'dark' : 'light'}` prop (read theme from appSlice)
   - Include `<Background />`, `<Controls />`, `<MiniMap />` children
