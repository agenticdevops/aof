1. Create `web-app/src/components/analytics/AgentUtilizationChart.tsx`:
   - Props: `{ data: Array<{ agent_id: string; uptime_percent: number; success_rate: number; event_count: number }> }`
   - Read dark mode: `const isDark = useAppSelector((state) => state.app.theme === 'dark')`
   - Color constants:
     * `textColor = isDark ? '#9ca3af' : '#6b7280'`
     * `gridColor = isDark ? '#374151' : '#e5e7eb'`
     * `tooltipBg = isDark ? '#1f2937' : '#ffffff'`
     * `tooltipBorder = isDark ? '#374151' : '#e5e7eb'`
   - Render:
     ```tsx
     <ResponsiveContainer width="100%" height={300}>
       <BarChart data={data}>
         <CartesianGrid strokeDasharray="3 3" stroke={gridColor} />
         <XAxis dataKey="agent_id" tick={{ fill: textColor }} fontSize={12} />
         <YAxis tick={{ fill: textColor }} domain={[0, 100]} />
         <Tooltip contentStyle={{ backgroundColor: tooltipBg, borderColor: tooltipBorder }} />
         <Legend />
         <Bar dataKey="uptime_percent" name="Uptime %" fill="#10b981" radius={[4, 4, 0, 0]} />
         <Bar dataKey="success_rate" name="Success %" fill="#3b82f6" radius={[4, 4, 0, 0]} />
       </BarChart>
     </ResponsiveContainer>
     ```
   - Wrap in a card: `bg-white dark:bg-gray-800 rounded-lg p-6 shadow-sm`
   - Title: "Agent Utilization" above chart
   - Empty state: "No agent metrics available" when data is empty

   - Render:

     ```tsx
     <ResponsiveContainer width="100%" height={300}>
       <LineChart data={data}>

         <XAxis dataKey="timestamp" tick={{ fill: textColor }} fontSize={12} />
         <YAxis tick={{ fill: textColor }} />
         <Tooltip contentStyle={{ backgroundColor: tooltipBg, borderColor: tooltipBorder }} />
         <Legend />

         <Line type="monotone" dataKey="failed" name="Failed" stroke="#ef4444" strokeWidth={2} dot={false} />
         <Line type="monotone" dataKey="total" name="Total" stroke="#6366f1" strokeWidth={2} dot={false} />
       </LineChart>
     </ResponsiveContainer>
     ```
   - Wrap in card like AgentUtilizationChart
   - Title: "Task Completion Trends"
   - NOTE: Since no time-series API exists yet, the Analytics page will generate mock trend data from current task snapshots (e.g., group tasks by creation date).
