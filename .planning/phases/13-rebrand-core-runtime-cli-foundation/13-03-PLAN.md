    `AgentManifest::from_yaml(content: &str) -> Result<Self, AgentixError>`:

    `AgentManifest::validate(&self) -> Result<(), AgentixError>`:
    - Name regex: `^[a-z][a-z0-9-]*[a-z0-9]$`, len <= 63
    - If model.preferred is Some, must contain exactly one `/`

    `AgentDefinition` (assembled runtime type):
    ```rust
    #[derive(Debug, Clone)]
    pub struct AgentDefinition {
        pub name: String,
        pub version: Option<String>,
        pub description: Option<String>,
        pub model_preferred: Option<String>,
        pub soul_content: String,              // From SOUL.md
        pub rules_content: Option<String>,     // From RULES.md
        pub skills: Vec<SkillEntry>,           // From skills/*/SKILL.md
        pub tools: Vec<ToolEntry>,             // From tools/*.yaml
        pub sub_agents: Vec<AgentDefinition>,  // From agents/*/
        // Runtime values (from workspace defaults or built-in defaults)
        pub max_iterations: u32,
        pub timeout_secs: u64,
        pub mode: AgentMode,
    }
    ```

    `AgentDefinition::resolved_system_prompt(&self) -> String`:
    - Start with soul_content
    - If rules_content is Some: append `\n\n## Constraints\n\n{rules_content}`
    - For each skill: append `\n\n## Skill: {skill.name}\n\n{skill.content}`
    - Return the assembled string

    `AgentDefinition::apply_workspace_defaults(&mut self, workspace: &WorkspaceConfig)`:
    - If model_preferred is None and workspace.spec.defaults.model is Some: set model_preferred
    - If workspace.spec.defaults.max_iterations is Some: set max_iterations
    - If workspace.spec.defaults.timeout is Some: parse and set timeout_secs
    - If workspace.spec.defaults.mode is Some: set mode

    `DirectoryLoader`:

    ```rust
        pub fn load(dir: &Path) -> Result<AgentDefinition, AgentixError> {
            // 1. Read and parse agent.yaml

            // 4. Read RULES.md (optional)

    ```

    For tools/*.yaml loading: each file is parsed as a `ToolEntry`. The YAML format:
    ```yaml
    name: kubectl
    type: cli  # or "mcp" or "shell"
    description: "..."
    command: kubectl
    args: ["{{subcommand}}"]
    ```
    Use serde with `#[serde(tag = "type", rename_all = "lowercase")]` or a manual enum to handle the type discriminator.

    `AgentLoader` (format detection + unified loading):
    ```rust
    pub enum AgentFormat { Directory, FlatYaml }

    impl AgentLoader {
        pub fn detect_format(path: &Path) -> AgentFormat {
            if path.is_dir() { AgentFormat::Directory } else { AgentFormat::FlatYaml }
        }

        pub fn load(path: &Path) -> Result<AgentDefinition, AgentixError> {
            match Self::detect_format(path) {
                AgentFormat::Directory => DirectoryLoader::load(path),
                AgentFormat::FlatYaml => FlatYamlLoader::load(path),
            }
        }
    }
    ```
