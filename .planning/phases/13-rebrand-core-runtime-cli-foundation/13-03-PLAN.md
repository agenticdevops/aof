    Define these types (replace all v1.0 types):

    ```rust
    /// Top-level agent document
    #[derive(Debug, Clone, Serialize, Deserialize)]
    #[serde(rename_all = "camelCase")]
    pub struct AgentSpec {
        pub api_version: String,  // "openagentix.dev/v1"
        pub kind: String,         // "Agent"
        pub metadata: AgentMetadata,
        pub spec: AgentSpecInner,
    }

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct AgentMetadata {
        pub name: String,
        #[serde(default = "default_namespace")]
        pub namespace: Option<String>,
        pub version: Option<String>,
        #[serde(default)]
        pub labels: HashMap<String, String>,
        #[serde(default)]
        pub annotations: HashMap<String, String>,
    }

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct AgentSpecInner {
        pub model: Option<String>,  // Optional — can inherit from workspace
        #[serde(default = "default_mode")]
        pub mode: AgentMode,
        pub system_prompt: Option<String>,
        pub system_prompt_file: Option<String>,
        #[serde(default = "default_max_iterations")]
        pub max_iterations: u32,
        #[serde(default = "default_timeout")]
        pub timeout: String,
        #[serde(default)]
        pub tools: Vec<ToolEntry>,
        #[serde(default)]
        pub mcp_servers: Vec<McpServerEntry>,
        #[serde(default)]
        pub triggers: Vec<serde_json::Value>,  // Placeholder for Phase 15
        #[serde(default)]
        pub notifications: Vec<NotificationEntry>,
        pub approval: Option<serde_json::Value>,  // Placeholder for Phase 20
        pub budget: Option<serde_json::Value>,    // Placeholder for Phase 17
        pub telemetry: Option<serde_json::Value>, // Placeholder for Phase 18
        #[serde(default)]
        pub env: HashMap<String, String>,
    }
    ```

    Define `AgentMode` enum: `Manual`, `SemiAutonomous`, `Autonomous` with serde rename `kebab-case`.

    Define `ToolEntry` with `name`, `type` (ToolType enum: Cli, Mcp, Shell), `description`, and type-specific fields using `#[serde(flatten)]` or dedicated fields:
    - `command` (for cli/shell)
    - `args` (for cli)
    - `server` (for mcp)

    Define `McpServerEntry` with `name`, `transport` (enum: Stdio, Sse, Http), `command`, `args`, `url`, `env`.

    Define `NotificationEntry` with `channel` (enum), `target`.

    Implement `AgentSpec::validate(&self) -> Result<(), AgentixError>`:
    - Check `api_version == "openagentix.dev/v1"`
    - Check `kind == "Agent"`
    - Validate `metadata.name` matches `^[a-z][a-z0-9-]*[a-z0-9]$` and len <= 63
    - Validate `metadata.namespace` if present (same pattern)
    - Validate `model` contains exactly one `/` (if present — workspace might provide it)
    - Validate `system_prompt` and `system_prompt_file` are mutually exclusive
    - Validate `max_iterations` is 1-100
    - Use `serde_path_to_error` for YAML parsing in a `from_yaml(content: &str)` constructor

    Implement `AgentSpec::from_yaml(content: &str) -> Result<Self, AgentixError>`:
    - Use `serde_path_to_error::deserialize` with `serde_yaml::Deserializer`
    - On error, return `AgentixError::YamlParse` with the field path and inner error message

    Implement `AgentSpec::parse_model(&self) -> Option<(&str, &str)>`:
    - Split model on `/` and return (provider, model_name) tuple

    **config.rs — Workspace configuration:**

    ```rust
    #[derive(Debug, Clone, Serialize, Deserialize)]
    #[serde(rename_all = "camelCase")]
    pub struct WorkspaceConfig {
        pub api_version: String,
        pub kind: String,  // "Workspace"
        pub metadata: WorkspaceMetadata,
        pub spec: WorkspaceSpec,
    }

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct WorkspaceMetadata {
        pub name: String,
    }

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct WorkspaceSpec {
        #[serde(default)]
        pub defaults: WorkspaceDefaults,
        #[serde(default)]
        pub providers: HashMap<String, ProviderConfig>,
        #[serde(default)]
        pub gateway: GatewayConfig,
        #[serde(default = "default_agents_dir")]
        pub agents_dir: String,
    }

    #[derive(Debug, Clone, Default, Serialize, Deserialize)]
    pub struct WorkspaceDefaults {
        pub model: Option<String>,
        pub max_iterations: Option<u32>,
        pub timeout: Option<String>,
        pub mode: Option<AgentMode>,
    }

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct ProviderConfig {
        pub api_key: Option<String>,
        pub base_url: Option<String>,
    }

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct GatewayConfig {
        #[serde(default = "default_host")]
        pub host: String,
        #[serde(default = "default_port")]
        pub port: u16,
    }
    ```
