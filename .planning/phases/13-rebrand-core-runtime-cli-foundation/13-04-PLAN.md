    **TDD GREEN phase.**

    Implement `ReActEngine` in react_loop.rs:

    ```rust
    pub struct ReActEngine {
        model: Arc<dyn Model>,
        tool_executor: Arc<dyn ToolExecutor>,
        max_iterations: u32,
        timeout: Duration,
    }
    ```

    Implement `ReActEngine::new(model, tool_executor, config)` — takes the LLM model, tool executor, and AgentSpec config.

    Implement `ReActEngine::run(input: &str, system_prompt: &str) -> Result<RunResult, AgentixError>`:

    The loop logic:
    ```
    1. Initialize conversation messages with system prompt + user input
    2. For each iteration (up to max_iterations):
       a. [Plan] Send messages to LLM, asking it to plan next steps
       b. Parse LLM response:
          - If response contains tool calls → [Act] execute each tool
          - If response is final answer (no tool calls) → return RunResult
       c. [Observe] Collect tool results (or errors) as observation text
       d. [Reflect] Add observation to messages, LLM reflects on results
       e. Emit ReActStep event
    3. If max_iterations reached, return RunResult with reached_max_iterations=true
    ```

    Key implementation details:
    - The LLM conversation is a growing list of messages. Each iteration appends assistant + tool_result + assistant messages.
    - Tool failures produce an observation like "Tool 'kubectl' failed: <error message>". This is NOT a loop error — it feeds back into the LLM for decision-making.
    - The LLM signals "done" by returning a response with no tool calls (just text). The loop then terminates.
    - Use `tokio::time::timeout` for the wall-clock timeout.
    - Events are collected in a `Vec<ReActEvent>` and also available via a channel (for streaming — will be wired in Plan 05).

    The system prompt should be augmented with ReAct instructions:
    ```
    You are an AI agent operating in a ReAct (Reason + Act) loop.

    For each step:
    1. **Plan**: Analyze the current situation and decide what to do next
    2. **Act**: Call a tool if needed, or provide your final answer
    3. **Observe**: Review the tool result
    4. **Reflect**: Decide if you need another step or have enough information

    When you have enough information to answer, respond without calling any tools.
    ```

    This prompt is prepended to the user's system_prompt.

    Run all tests: `cargo test -p agentix-runtime --test react_loop_test`
