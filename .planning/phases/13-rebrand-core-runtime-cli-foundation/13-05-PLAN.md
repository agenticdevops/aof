    Implement in streaming.rs:

    **SseEncoder:**
    - `encode(event: &ReActEvent) -> String` — Converts event to SSE text format.
    - SSE format: `event: <event_type>\ndata: <json>\n\n`
    - Event types: `react_step` (for Step events), `complete` (for RunComplete), `error` (for Error)
    - Data is JSON-serialized event payload.

    **TextFormatter:**
    - `format(event: &ReActEvent) -> String` — Converts event to human-readable text.
    - Uses labeled sections: `[Plan]`, `[Act]`, `[Observe]`, `[Reflect]`
    - Per CONTEXT.md: colors with auto-detect. `use_colors` flag controls colored output.
    - When colors enabled: `[Plan]` in cyan, `[Act]` in yellow, `[Observe]` in green, `[Reflect]` in blue, errors in red.
    - Use the `colored` crate for terminal colors.

    **JsonFormatter:**
    - `format(event: &ReActEvent) -> String` — Converts event to single-line JSON (NDJSON).
    - Each event is a complete JSON object on one line.
    - Includes a `timestamp` field (ISO 8601) and `event_type` field.

    **Wire streaming into ReActEngine:**
    Update react_loop.rs to accept an optional `EventStream` (broadcast sender):
    - `ReActEngine::with_event_stream(mut self, tx: EventStream) -> Self`
    - In the loop, after each phase (plan/act/observe/reflect), send the corresponding event to the channel.
    - If no event stream is configured, events are silently dropped (no-op).

    Add `colored` dependency to agentix-runtime/Cargo.toml if not already present.
