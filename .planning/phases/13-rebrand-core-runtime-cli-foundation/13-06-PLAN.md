    **router.rs — Gateway startup and axum router:**

    ```rust
    pub struct Gateway {
        agent_manager: Arc<AgentManager>,
        config: GatewayConfig,
    }

    impl Gateway {
        pub async fn start(config: GatewayConfig, workspace_config: Option<WorkspaceConfig>, agents_dir: &Path) -> Result<(), AgentixError> {
            let manager = Arc::new(AgentManager::new(workspace_config));
            manager.load_agents_dir(agents_dir)?;

            let app = api::create_router(manager.clone());

            let addr = format!("{}:{}", config.host, config.port);
            println!("Gateway started on {}", addr);
            println!("Loaded {} agents", manager.list_agents().len());

            let listener = tokio::net::TcpListener::bind(&addr).await?;
            axum::serve(listener, app).await?;
            Ok(())
        }
    }
    ```

    **api.rs — HTTP endpoints:**

    Create axum router with these endpoints:

    ```
    GET  /healthz                          → 200 OK
    GET  /api/v1/agents                    → List all agents (JSON array of AgentSummary)
    POST /api/v1/agents                    → Register a new agent (JSON AgentSpec YAML body)
    GET  /api/v1/agents/:name              → Get agent details (JSON AgentSpec)
    PUT  /api/v1/agents/:name              → Update an existing agent (JSON AgentSpec YAML body)
    POST /api/v1/agents/:name/run          → Start a run, return SSE stream
    GET  /api/v1/agents/:name/runs         → List runs for agent (JSON array of RunSummary)
    GET  /api/v1/agents/:name/runs/:id     → Get run details (JSON RunState)
    GET  /api/v1/agents/:name/runs/:id/logs → Get run events/logs (JSON array of ReActEvent)
    DELETE /api/v1/agents/:name/runs/:id   → Stop a running agent
    ```

    **POST /api/v1/agents** — Register a new agent:
    - Request body: `{"yaml": "apiVersion: openagentix.dev/v1\nkind: Agent\n..."}` (raw YAML string in a JSON wrapper)
    - Parses with `AgentSpec::from_yaml`, validates, merges workspace defaults, adds to AgentManager
    - Returns 201 with `{"name": "agent-name", "status": "ready"}` on success
    - Returns 400 with rustc-style error details if validation fails
    - Returns 409 if agent with same name already exists (use PUT to update)

    **PUT /api/v1/agents/:name** — Update an existing agent:
    - Same body format as POST
    - Validates the new spec, replaces the existing agent in AgentManager
    - Returns 200 with `{"name": "agent-name", "status": "ready"}`
    - Returns 404 if agent doesn't exist (use POST to create)
    - Returns 400 if validation fails

    Also add corresponding methods to AgentManager:
    - `register_agent(spec: AgentSpec) -> Result<String, AgentixError>` — Validates, merges workspace defaults, inserts into agents map. Returns error if name exists.
    - `update_agent(name: &str, spec: AgentSpec) -> Result<(), AgentixError>` — Validates, merges workspace defaults, replaces existing. Returns error if not found.

    **POST /api/v1/agents/:name/run** is the key endpoint:
    - Request body: `{"input": "your question or task"}`
    - Response: SSE stream (`Content-Type: text/event-stream`)
    - Uses `axum::response::Sse` with `SseEncoder` from streaming.rs
    - Each ReAct event is streamed as an SSE message as it happens
    - Query param `?format=json` returns NDJSON instead of SSE
    - If agent not found: 404 with `{"error": "Agent 'name' not found"}`

    **Error response format (all endpoints):**
    ```json
    {"error": "description", "details": "optional extra context"}
    ```

    Enable CORS via tower-http (allow all origins for development — will be locked down in Phase 19).
