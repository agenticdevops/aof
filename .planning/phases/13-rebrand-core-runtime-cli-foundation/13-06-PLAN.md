    ```rust
    pub struct AgentManager {
        agents: DashMap<String, LoadedAgent>,
        runs: DashMap<String, RunState>,

    pub struct LoadedAgent {
        pub definition: AgentDefinition,   // Assembled (not raw manifest)
        pub source_path: PathBuf,          // Where it was loaded from
        pub loaded_at: chrono::DateTime<chrono::Utc>,
        pub status: AgentStatus,
    }

    pub enum AgentStatus { Ready, Running, Error(String) }

    pub struct RunState {
        pub id: String,
        pub agent_name: String,
        pub started_at: chrono::DateTime<chrono::Utc>,
        pub completed_at: Option<chrono::DateTime<chrono::Utc>>,
        pub status: RunStatus,
        pub input: String,
        pub output: Option<String>,
        pub iterations: u32,
        pub events: Vec<ReActEvent>,
        pub cancel_tx: Option<tokio::sync::oneshot::Sender<()>>,
    }

    pub enum RunStatus { Running, Completed, Failed(String), Cancelled }
    ```

    Implement `AgentManager::new(workspace_config: Option<WorkspaceConfig>) -> Arc<Self>` (returns Arc for sharing across axum handlers).

    Implement `AgentManager::load_from_dir(&self, dir: &Path) -> Vec<String>`:
    - Scan the directory for entries
    - For each subdirectory: call `AgentLoader::load(subdir_path)` (directory format)
    - For each `*.yaml` / `*.yml` file: call `AgentLoader::load(file_path)` (flat YAML format)
    - On success: call `definition.apply_workspace_defaults(workspace_config)`, insert into agents map
    - On error: `tracing::warn!("Failed to load agent from {:?}: {}", path, err)` — continue, do not abort
    - Return list of successfully loaded agent names

    Implement `AgentManager::register_from_yaml(&self, yaml_content: &str) -> Result<String, AgentixError>`:
    - Parse with `FlatYamlLoader` (since the API sends raw YAML)
    - Apply workspace defaults
    - Insert into agents map, return agent name
    - Error if agent with same name already exists

    Implement `AgentManager::update_from_yaml(&self, name: &str, yaml_content: &str) -> Result<(), AgentixError>`:
    - Parse, apply defaults, replace existing agent (error if not found)

    Implement `AgentManager::start_run(&self, agent_name: &str, input: &str) -> Result<(String, EventReceiver), AgentixError>`:
    - Get agent definition from agents map
    - Create run_id = uuid::Uuid::new_v4().to_string()
    - Create broadcast channel: `tokio::sync::broadcast::channel::<ReActEvent>(256)`
    - Clone the event sender for the run
    - Create cancel channel: `tokio::sync::oneshot::channel::<()>()`
    - Store RunState in runs map with status=Running
    - Spawn tokio task:
      ```rust
      tokio::spawn(async move {
          // Create LLM provider from definition.model_preferred + workspace providers
          // Create ShellToolExecutor
          // Create ReActEngine with event sender wired in
          // Run the engine
          // On completion: update RunState in runs map (status=Completed, output, iterations)
      })
      ```
    - Return (run_id, event_receiver)

    For LLM provider creation: use a `create_provider_from_definition` helper that:

    - Splits on `/` to get provider name and model name
    - Looks up provider in workspace_config.spec.providers
    - Creates provider via agentix-llm's factory function
    - Returns helpful error if provider not configured

    Implement `AgentManager::stop_run(&self, run_id: &str) -> Result<(), AgentixError>`:

    **router.rs — Gateway startup:**

    ```rust
    pub struct Gateway;

    impl Gateway {
        pub async fn start(
            config: GatewayConfig,
            workspace_config: Option<WorkspaceConfig>,
            agents_dir: &Path,
        ) -> Result<(), AgentixError> {
            let manager = AgentManager::new(workspace_config);
            let loaded = manager.load_from_dir(agents_dir);
            let addr = format!("{}:{}", config.host, config.port);
            println!("OpenAgentiX Gateway");
            println!("Listening on http://{}", addr);
            println!("Loaded {} agents from {}", loaded.len(), agents_dir.display());
            for name in &loaded {
                println!("  - {}", name);
            }
            let app = api::create_router(manager);
            let listener = tokio::net::TcpListener::bind(&addr).await
                .map_err(|e| AgentixError::Other(anyhow::anyhow!("Failed to bind {}: {}", addr, e)))?;
            axum::serve(listener, app).await
                .map_err(|e| AgentixError::Other(anyhow::anyhow!("Gateway error: {}", e)))?;
            Ok(())
        }
    }
    ```

    **api.rs — HTTP endpoints using axum:**

    Router function:
    ```rust
    pub fn create_router(manager: Arc<AgentManager>) -> Router {
        Router::new()
            .route("/healthz", get(health))
            .route("/api/v1/agents", get(list_agents).post(register_agent))
            .route("/api/v1/agents/:name", get(get_agent).put(update_agent))
            .route("/api/v1/agents/:name/run", post(run_agent))
            .route("/api/v1/agents/:name/runs", get(list_runs))
            .route("/api/v1/agents/:name/runs/:run_id", get(get_run))
            .route("/api/v1/agents/:name/runs/:run_id/logs", get(get_run_logs))
            .route("/api/v1/agents/:name/runs/:run_id", delete(stop_run))
            .layer(CorsLayer::permissive())
            .with_state(manager)
    }
    ```

    Handler implementations:

    **`GET /healthz`** → `200 OK` with `{"status":"ok","version":env!("CARGO_PKG_VERSION")}`

    **`GET /api/v1/agents`** → JSON array of AgentSummary

    **`POST /api/v1/agents`**:
    - Body: `{"yaml": "<raw agent yaml string>"}`
    - Calls `manager.register_from_yaml(body.yaml)`
    - 201 `{"name":"...", "status":"ready"}` on success
    - 409 if agent exists (use PUT to update)
    - 400 with `{"error":"...", "field":"spec.model"}` if validation fails

    **`PUT /api/v1/agents/:name`**:
    - Same body as POST
    - Calls `manager.update_from_yaml(name, body.yaml)`
    - 200 on success, 404 if not found, 400 if invalid

    **`POST /api/v1/agents/:name/run`**:
    - Body: `{"input": "user task"}`
    - Call `manager.start_run(name, input)` → (run_id, event_receiver)
    - Stream response via axum SSE:
      ```rust
      let stream = ReceiverStream::from(event_receiver)
          .map(|event| Ok::<_, Infallible>(
              axum::response::sse::Event::default()
                  .data(SseEncoder::encode_data(&event))
                  .event(SseEncoder::encode_event_name(&event))
          ));
      Sse::new(stream).keep_alive(KeepAlive::default())
      ```
    - Query param `?format=json`: return NDJSON via regular streaming body instead of SSE
    - 404 if agent not found

    **`DELETE /api/v1/agents/:name/runs/:run_id`**:
    - Calls `manager.stop_run(run_id)`
    - 200 `{"message":"Run stopped"}` on success, 404 if not found

    **Error response format (all handlers):**
    ```json
    {"error": "human-readable message", "field": "optional.field.path"}
    ```
    Return this as a JSON body with appropriate status code.
