    Add `Init` variant to cli.rs Commands enum:
    ```rust
    /// Create a new agent YAML file
    Init {
        /// Agent name (prompted interactively if omitted)
        name: Option<String>,

        /// Output file path (default: ./agents/<name>.yaml)
        #[arg(long, short)]
        output: Option<String>,

        /// Skip interactive prompts, generate minimal agent
        #[arg(long)]
        non_interactive: bool,
    },
    ```

    Add `pub mod init;` to commands/mod.rs.

    **init.rs — Agent YAML scaffolder:**

    Interactive flow:
    1. Prompt for agent name (if not provided as arg). Validate against name regex.
    2. Prompt for model (suggest from workspace config defaults if agentix.yaml exists, otherwise suggest "anthropic/claude-sonnet-4-6").
    3. Prompt for system prompt: "Enter system prompt (or path to .md file):"
       - If input starts with `.` or `/` or ends with `.md`, use `system_prompt_file`
       - Otherwise use `system_prompt` (inline)
    4. Prompt for mode: manual, semi-autonomous, autonomous (default: autonomous).
    5. Prompt for max iterations (default: 10).

    Generate the YAML using `AgentSpec` serialization (not string formatting — ensures valid YAML):
    - Create an `AgentSpec` struct with the provided values
    - Serialize with `serde_yaml::to_string`
    - Write to output path

    Validate the generated YAML by re-parsing it with `AgentSpec::from_yaml` and running `validate()`. This ensures we never generate invalid configs.

    Output path logic:
    - If `--output` specified, use it
    - Otherwise, write to `./agents/<name>.yaml`
    - If file exists, prompt "File exists. Overwrite? (y/n)"
    - Create parent directories if needed

    After writing:

    ```
    Next steps:
      1. Edit the system prompt in ./agents/dba-optimizer.yaml
      2. Add tools if needed (see docs: https://docs.openagentix.org/spec/agent-yaml-v1)
      3. agentix validate agents/dba-optimizer.yaml
    ```

    For `--non-interactive` mode: require name as arg, use workspace default model (or "anthropic/claude-sonnet-4-6"), generate minimal agent with placeholder system prompt.
