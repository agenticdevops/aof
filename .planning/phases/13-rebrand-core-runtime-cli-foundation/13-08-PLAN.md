    Add `Init` variant to cli.rs Commands enum:
    ```rust
    /// Scaffold a new agent directory
    Init {
        /// Agent name
        name: Option<String>,
        /// Parent directory for the new agent directory (default: ./agents)
        #[arg(long, short, default_value = "./agents")]
        output_dir: String,
        /// Non-interactive mode (requires --name)
        #[arg(long)]
        non_interactive: bool,
    },
    ```

    Add `pub mod init;` to commands/mod.rs.

    **init.rs — Agent directory scaffolder:**

    The `init` command creates a GitAgent-compatible agent directory:
    ```
    <output_dir>/<name>/
    ├── agent.yaml    # Minimal manifest
    └── SOUL.md       # System prompt / identity
    ```
    Optionally creates RULES.md if the user provides constraints.

    Interactive flow (when not `--non-interactive`):
    1. Prompt "Agent name:" if not provided as arg. Validate against `^[a-z][a-z0-9-]*[a-z0-9]$`. Re-prompt on invalid input.
    2. Prompt "Model (e.g., anthropic/claude-sonnet-4-6, press Enter to use workspace default):" — accept empty for None.
    3. Prompt "Brief description (optional):"
    4. Prompt "What is this agent's identity and purpose? (This becomes SOUL.md)" — accept multi-line input until user enters a blank line.
    5. Prompt "Any hard constraints (RULES.md)? Enter rules or press Enter to skip:" — same multi-line until blank line. If empty, skip creating RULES.md.

    Generate files:

    **agent.yaml** content (use serde_yaml::to_string of AgentManifest struct):
    ```yaml
    spec_version: "0.1.0"
    name: my-agent
    version: 0.1.0
    description: A helpful assistant
    model:
      preferred: anthropic/claude-sonnet-4-6  # omit this field if user chose workspace default
    ```

    **SOUL.md** content: the user's identity/purpose text, or if none provided in non-interactive mode:
    ```markdown
    # My Agent

    You are a helpful AI assistant.

    ## Purpose

    [Describe what this agent does and its goals here.]

    ## Approach

    Think step by step. Be concise and precise in your responses.
    ```

    **RULES.md** content (only created if user provided constraints):
    ```markdown
    # Rules

    [User-provided constraints]
    ```

    Directory creation logic:
    - Check if `<output_dir>/<name>/` already exists — if yes, prompt "Directory already exists. Overwrite? (y/n)" or in non-interactive mode, skip with a warning.
    - Create parent directories with `std::fs::create_dir_all`.

    Validate generated agent directory by calling `DirectoryLoader::load(path)` after writing. If validation fails, print error and remove the created directory.

    After creating:
    ```
    Created agent directory: ./agents/my-agent/
      agent.yaml    (manifest)
      SOUL.md       (identity)

    Next steps:
      1. Edit ./agents/my-agent/SOUL.md to define your agent
      2. Add tools to ./agents/my-agent/tools/ (optional)
      3. agentix validate ./agents/my-agent
      4. agentix gateway start
    ```

    Non-interactive mode requires `--name`. Uses workspace default model (reads `./agentix.yaml` if present). Generates a placeholder SOUL.md with the agent name. Does NOT create RULES.md.

    Also create the quickstart reference files:

    **onboard.rs — Interactive workspace setup:**

    Onboard creates a complete workspace: `agentix.yaml` + `agents/hello-world/` directory.

    Check if `./agentix.yaml` already exists. If yes: "Workspace already exists at ./agentix.yaml. Run `agentix init` to add more agents." Exit gracefully.

    Interactive flow:

    1. Print welcome banner:
       ```
       Welcome to OpenAgentiX!
       Let's set up your workspace.
       ```

    2. Workspace name prompt: "Workspace name (e.g., my-project):" — validate as slug. Default: basename of current directory.

    3. LLM provider setup:
       - "Which LLM provider? (1) Anthropic  (2) OpenAI  (3) Google  (4) Ollama  (5) Skip"
       - For Anthropic/OpenAI/Google: "API key (or env var reference like ${ANTHROPIC_API_KEY}):"
         - If user enters `${...}` format: write as-is, print "Remember to export ANTHROPIC_API_KEY before starting the gateway"
         - If user enters actual key: write as-is (they can replace with env ref later)
       - For Ollama: "Ollama URL (default: http://localhost:11434):"
       - "Default model (e.g., anthropic/claude-sonnet-4-6):" — suggest appropriate model for chosen provider
       - "Add another provider? (y/n)"

    4. Gateway port: "Gateway port (default: 7777):"

    5. Agents directory: "Agents directory (default: ./agents):"

    6. Generate and write `./agentix.yaml` using `serde_yaml::to_string` of a `WorkspaceConfig` struct. Use the user's inputs.

    7. Create the hello-world agent directory using the same logic as `agentix init --non-interactive --name hello-world`:
       - Write `<agents_dir>/hello-world/agent.yaml` with the chosen default model
       - Write `<agents_dir>/hello-world/SOUL.md` with the starter content

    8. Offer to start gateway:
       - "Start the gateway now? (y/n)"
       - If yes: call `agentix_runtime::gateway::Gateway::start(config, Some(workspace_config), agents_dir).await`
       - If no: print "Run `agentix gateway start` when ready"

    9. Print summary:
       ```
       Workspace created!
         Config:  ./agentix.yaml
         Agents:  ./agents/hello-world/
         Gateway: http://127.0.0.1:7777

       Next steps:
         agentix gateway start          # Start the gateway
         agentix agents                 # List loaded agents
         agentix init --name my-agent  # Create more agents
       ```

    Non-interactive mode (`--non-interactive`):
    - Use all defaults: workspace name = current dir basename, no providers (commented-out section in agentix.yaml), port 7777, agents_dir=./agents
    - Create hello-world agent with model field omitted (inherits from workspace defaults which are empty — user must fill in)
    - Print instructions to set up providers in agentix.yaml before starting gateway

    **TTY check**: If stdin is not a TTY and `--non-interactive` not given, print error:

    Use `std::io::IsTerminal::is_terminal(&std::io::stdin())` for the TTY check.
