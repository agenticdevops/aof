    **Provider auth abstraction (BYOK + consumer subscription foundation):**

    Per CONTEXT.md locked decision on BYOK + consumer subscriptions, define a `ProviderAuth` trait in `agentix-llm/src/auth.rs`:

    ```rust
    /// Authentication method for LLM providers.
    /// ApiKey is implemented now. OAuthToken (consumer subscription auth via
    /// ChatGPT/Claude/Gemini accounts) will be implemented in a dedicated phase.
    #[derive(Debug, Clone, Serialize, Deserialize)]
    #[serde(tag = "type", rename_all = "snake_case")]
    pub enum ProviderAuth {
        /// Standard API key authentication (BYOK)
        ApiKey { key: String },
        /// OAuth token from consumer subscription (ChatGPT Plus, Claude Pro, Gemini Advanced)
        /// NOT YET IMPLEMENTED — placeholder for future phase
        OAuthToken {
            access_token: String,
            refresh_token: Option<String>,
            provider: String,
            expires_at: Option<chrono::DateTime<chrono::Utc>>,
        },
    }

    impl ProviderAuth {
        pub fn api_key(key: impl Into<String>) -> Self {
            Self::ApiKey { key: key.into() }
        }

        /// Returns the bearer token or API key string for HTTP headers
        pub fn authorization_header(&self) -> Result<String, AgentixError> {
            match self {
                Self::ApiKey { key } => Ok(key.clone()),
                Self::OAuthToken { .. } => Err(AgentixError::Other(
                    anyhow::anyhow!("OAuth consumer subscription auth not yet implemented. Use API key authentication for now.")
                )),
            }
        }
    }
    ```
