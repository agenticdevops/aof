    **LLM provider factory (agentix-llm):**

    Add a public factory function to agentix-llm that resolves a "provider/model" string using workspace provider config:

    ```rust
    /// Create an LLM model instance from a "provider/model" string and provider config map.
    /// provider_configs comes from WorkspaceConfig::spec::providers.
    pub fn create_provider(
        model_spec: &str,
        provider_configs: &HashMap<String, ProviderConfig>,
    ) -> Result<Box<dyn Model + Send + Sync>, AgentixError> {
        let (provider_name, model_name) = model_spec.split_once('/').ok_or_else(|| {
            AgentixError::SpecValidation(format!(
                "Invalid model format '{}'. Expected 'provider/model' (e.g., 'anthropic/claude-sonnet-4-6')",
                model_spec
            ))
        })?;

        match provider_name {
            "anthropic" => {
                let cfg = provider_configs.get("anthropic").ok_or_else(|| {
                    AgentixError::ConfigNotFound(
                        "Provider 'anthropic' not configured. Add to agentix.yaml:\n  providers:\n    anthropic:\n      api_key: \"${ANTHROPIC_API_KEY}\"".into()
                    )
                })?;
                let api_key = cfg.api_key.as_deref().ok_or_else(|| {
                    AgentixError::ConfigNotFound("providers.anthropic.api_key is not set".into())
                })?;
                Ok(Box::new(AnthropicProvider::new(api_key, model_name)))
            },
            "openai" => {
                let cfg = provider_configs.get("openai").ok_or_else(|| {
                    AgentixError::ConfigNotFound(
                        "Provider 'openai' not configured. Add to agentix.yaml:\n  providers:\n    openai:\n      api_key: \"${OPENAI_API_KEY}\"".into()
                    )
                })?;
                let api_key = cfg.api_key.as_deref().ok_or_else(|| {
                    AgentixError::ConfigNotFound("providers.openai.api_key is not set".into())
                })?;
                let base_url = cfg.base_url.as_deref().unwrap_or("https://api.openai.com/v1");
                Ok(Box::new(OpenAiProvider::new(api_key, model_name, base_url)))
            },
            "google" => {
                let cfg = provider_configs.get("google").ok_or_else(|| {
                    AgentixError::ConfigNotFound(
                        "Provider 'google' not configured. Add to agentix.yaml:\n  providers:\n    google:\n      api_key: \"${GOOGLE_API_KEY}\"".into()
                    )
                })?;
                let api_key = cfg.api_key.as_deref().ok_or_else(|| {
                    AgentixError::ConfigNotFound("providers.google.api_key is not set".into())
                })?;
                Ok(Box::new(GoogleProvider::new(api_key, model_name)))
            },
            "ollama" => {
                let cfg = provider_configs.get("ollama");
                let base_url = cfg.and_then(|c| c.base_url.as_deref()).unwrap_or("http://localhost:11434");
                Ok(Box::new(OllamaProvider::new(base_url, model_name)))
            },
            other => Err(AgentixError::SpecValidation(format!(
                "Unknown provider '{}'. Supported: anthropic, openai, google, ollama", other
            ))),
        }
    }
    ```

        let agent = self.agents.get(agent_name)
            .ok_or_else(|| AgentixError::ConfigNotFound(format!("Agent '{}' not found", agent_name)))?;

        let model_spec = agent.definition.model_preferred.as_deref()
            .ok_or_else(|| AgentixError::SpecValidation(
                format!("Agent '{}' has no model configured. Set model.preferred in agent.yaml or spec.defaults.model in agentix.yaml", agent_name)
            ))?;

        let empty_providers = HashMap::new();
        let provider_configs = self.workspace_config.as_ref()
            .map(|c| &c.spec.providers)
            .unwrap_or(&empty_providers);

        let model = agentix_llm::create_provider(model_spec, provider_configs)?;

        let definition = agent.definition.clone();
        let react_config = ReActConfig::from_definition(&definition);

        let (event_tx, event_rx) = tokio::sync::broadcast::channel::<ReActEvent>(256);
        let (cancel_tx, cancel_rx) = tokio::sync::oneshot::channel::<()>();

    **Enterprise Agent Automation Platform**

    Define AI agents as directories. Run them on demand or on schedule.
    Stream real-time ReAct loop output. Track everything.

    ## Quick Start

    ```bash
    # Install
    cargo install agentix

    # Set up a workspace
    agentix onboard

    # Start the gateway
    agentix gateway start

    # List agents
    agentix agents

    # Create a new agent
    agentix init --name my-agent
    ```

    ## Agent Directories

    Agents are directories, not single files:

    ```
    agents/my-agent/
    ├── agent.yaml    # Metadata + model
    └── SOUL.md       # Identity + system prompt
    ```

    That's all you need. Add tools, skills, and sub-agents as your needs grow.

    ## Features

    - **GitAgent-compatible** — Agent directories with SOUL.md, RULES.md, skills/, tools/
    - **ReAct loop** — Plan → Act → Observe → Reflect execution model
    - **Streaming output** — SSE for HTTP, text/JSON for CLI
    - **Multi-provider** — Anthropic, OpenAI, Google, Ollama
    - **Gateway architecture** — REST API, run management, agent lifecycle
    - **Skills composition** — Reusable capability modules (Phase 14)
    - **Cost tracking** — Per-run and per-agent cost monitoring (Phase 17)
    - **Approval workflows** — Human-in-the-loop gate (Phase 20)
