Add a webhook ingestion route to the gateway HTTP server.

In `api.rs`, add:
```rust
.route("/webhooks/:trigger_id", post(handle_webhook))
```

Handler `handle_webhook`:
1. Extract `trigger_id` from path
2. Look up in `AgentManager::trigger_registry` — if not found return 404
3. Determine trigger type: check if it's a WebhookTrigger, GitHubTrigger, or JiraTrigger
4. Extract raw body bytes and relevant headers
5. Call the appropriate `receive_payload()` method
6. If a TriggerEvent is returned (not filtered), call `AgentManager::run_agent_with_trigger()`
7. Return 200 with `{"accepted": true, "run_id": "..."}`

Since TriggerTrait doesn't expose `receive_payload()` directly (it's type-specific), use an `HttpTrigger` marker trait or a `WebhookHandler` trait that extends TriggerTrait:

```rust
/// Implemented by triggers that can receive HTTP payloads directly.
pub trait HttpTriggerHandler: TriggerTrait {
    fn handle_http(
        &self,
        headers: &HashMap<String, String>,
        body: serde_json::Value,
    ) -> Result<Option<TriggerEvent>, AgentixError>;
}
```

Or use an `Arc<dyn Any>` downcast approach. Choose the cleanest design that compiles.
