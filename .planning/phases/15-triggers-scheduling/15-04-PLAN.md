Create `crates/agentix-triggers/src/channel_mention.rs`.

Design: ChannelMentionTrigger is a unified handler that supports all three platforms via a `ChannelPlatform` enum:

```rust
pub enum ChannelPlatform {
    Slack { bot_token: String, signing_secret: String },
    Discord { bot_token: String, application_id: String },
    Telegram { bot_token: String },
}

pub struct ChannelMentionTrigger {
    id: String,
    agent_name: String,
    platform: ChannelPlatform,
    sender: tokio::sync::Mutex<Option<tokio::sync::mpsc::Sender<(String, TriggerEvent)>>>,
}

impl ChannelMentionTrigger {
    pub fn for_slack(agent_name: impl Into<String>, trigger_id: impl Into<String>,
                     bot_token: impl Into<String>, signing_secret: impl Into<String>) -> Self

    pub fn for_discord(agent_name: impl Into<String>, trigger_id: impl Into<String>,
                       bot_token: impl Into<String>, application_id: impl Into<String>) -> Self

    pub fn for_telegram(agent_name: impl Into<String>, trigger_id: impl Into<String>,
                        bot_token: impl Into<String>) -> Self

    /// Process an inbound HTTP webhook event.
    /// Returns Some(TriggerEvent) if this is a mention event, None if filtered out.
    pub fn process_event(
        &self,
        payload: serde_json::Value,
        headers: &std::collections::HashMap<String, String>,
    ) -> Result<Option<TriggerEvent>, AgentixError>
}
```

**Slack processing** (in `process_event`):
- Check payload.event.type == "app_mention" OR type == "event_callback" with event.type == "app_mention"
- Verify X-Slack-Signature header if signing_secret is set (use hmac+sha2, same as GitHub but with v0 prefix)
- Return TriggerEvent{source: Slack, payload: {channel, user, text, ts}}

**Discord processing**:
- Check `t` == "MESSAGE_CREATE" and `d.content` contains `<@BOT_USER_ID>` — but since we don't always know the bot ID at parse time, check for `<@` in content
- Return TriggerEvent{source: Discord, payload: {channel_id, guild_id, user_id, content}}

**Telegram processing**:
- Check `message.text` contains `@{bot_username}` OR starts with `/`
- Return TriggerEvent{source: Telegram, payload: {chat_id, user_id, text, username}}

Implement TriggerTrait. `start()` stores sender (passive trigger).

Add to lib.rs:
```rust
pub mod channel_mention;
pub use channel_mention::{ChannelMentionTrigger, ChannelPlatform};
```
