Create `crates/agentix-runtime/src/cost_store.rs` modeled on `run_store.rs`. Use `rusqlite` (already in Cargo.toml) with `parking_lot::Mutex` for the connection.

**Schema (in CostStore::open):**
```sql
CREATE TABLE IF NOT EXISTS cost_records (
    id              TEXT PRIMARY KEY,
    agent_name      TEXT NOT NULL,
    run_id          TEXT NOT NULL,
    model           TEXT NOT NULL,
    provider        TEXT NOT NULL,
    input_tokens    INTEGER NOT NULL DEFAULT 0,
    output_tokens   INTEGER NOT NULL DEFAULT 0,
    cost_usd        REAL NOT NULL DEFAULT 0.0,
    actual_cost_usd REAL,
    recorded_at     TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_cost_agent   ON cost_records(agent_name);
CREATE INDEX IF NOT EXISTS idx_cost_run     ON cost_records(run_id);
CREATE INDEX IF NOT EXISTS idx_cost_recorded ON cost_records(recorded_at DESC);
```

**impl CostStore:**

`open(path: &str) -> Result<Self, AgentixError>` — same pattern as RunStore::open. Use `":memory:"` for tests.

`insert_record(&self, record: &CostRecord) -> Result<(), AgentixError>` — INSERT OR IGNORE, maps CostRecord fields to columns.

`get_run_summary(&self, run_id: &str) -> Result<RunCostSummary, AgentixError>` — SQL:
```sql
SELECT agent_name, model,
       SUM(input_tokens) as total_input,
       SUM(output_tokens) as total_output,
       SUM(COALESCE(actual_cost_usd, cost_usd)) as total_cost,
       MIN(recorded_at) as started_at
FROM cost_records WHERE run_id = ?1
GROUP BY agent_name, model
```
If no rows, return error "no cost records for run {run_id}".

`get_agent_summary(&self, agent_name: &str) -> Result<CostSummary, AgentixError>` — SQL:
```sql
SELECT COUNT(DISTINCT run_id) as total_runs,
       SUM(input_tokens) as total_input,
       SUM(output_tokens) as total_output,
       SUM(COALESCE(actual_cost_usd, cost_usd)) as total_cost,
       MAX(recorded_at) as last_run_at
FROM cost_records WHERE agent_name = ?1
```

`list_run_summaries(&self, agent_name: &str, limit: usize) -> Result<Vec<RunCostSummary>, AgentixError>` — group by run_id, ordered by started_at DESC, apply LIMIT.

`list_all_summaries(&self) -> Result<Vec<CostSummary>, AgentixError>` — one row per distinct agent_name, same aggregation as get_agent_summary but across all agents.

Add `pub mod cost_store;` to `crates/agentix-runtime/src/lib.rs` and re-export `pub use cost_store::CostStore;`.
