```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TraceContext {
    pub trace_id: String,
    pub span_id: String,
    pub parent_span_id: Option<String>,
    pub agent_name: String,
    pub run_id: String,
}
```

`TraceContext::new_root(agent_name: &str, run_id: &str) -> Self` — generates trace_id and span_id using `uuid::Uuid::new_v4().to_string()`. parent_span_id is None.

`TraceContext::child_span(&self, name: &str, kind: SpanKind) -> SpanRecord` — creates a new SpanRecord with:
- span_id = new UUID
- parent_span_id = Some(self.span_id.clone())
- trace_id = self.trace_id.clone()
- name, kind as provided
- start_time = Utc::now()
- end_time = None
- duration_ms = None
- status = SpanStatus::Ok
- attributes = empty HashMap

**SpanRecord:**
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SpanRecord {
    pub span_id: String,
    pub parent_span_id: Option<String>,
    pub trace_id: String,
    pub name: String,
    pub kind: SpanKind,
    pub start_time: chrono::DateTime<chrono::Utc>,
    pub end_time: Option<chrono::DateTime<chrono::Utc>>,
    pub duration_ms: Option<u64>,
    pub status: SpanStatus,
    pub attributes: HashMap<String, String>,
}
```

`SpanRecord::complete(&mut self)` — sets end_time = Some(Utc::now()), computes duration_ms from start_time to end_time, keeps status as-is (Ok).

`SpanRecord::complete_with_error(&mut self, error: &str)` — sets end_time = Some(Utc::now()), computes duration_ms, sets status = SpanStatus::Error(error.to_string()).

`SpanRecord::with_attribute(mut self, key: &str, value: &str) -> Self` — builder-style attribute insertion.

Create `docs/concepts/telemetry.md` covering:

1. **Overview** — How OpenAgentiX provides observability through OpenTelemetry-compatible traces, metrics, and structured logs. Every agent run produces a trace with spans for each loop iteration, LLM call, tool call, and research phase.

2. **Trace Model** — Document the trace hierarchy:
   - Root span: one per agent run (SpanKind::Run)
   - Iteration spans: one per ReAct loop cycle (SpanKind::Iteration), children of root
   - LLM call spans: one per model.generate() call (SpanKind::LlmCall), children of iteration
   - Tool call spans: one per tool dispatch (SpanKind::ToolCall), children of iteration
   - Research spans: one per research phase (SpanKind::Research), child of root
   - Memory recall spans: one per vector memory search (SpanKind::MemoryRecall), child of root

3. **Correlation IDs** — Every span carries a trace_id (unique per run) and span_id (unique per span). These IDs propagate into structured log entries so logs can be correlated with traces.

4. **Structured Logs** — Document the StructuredLogEntry JSON format:
   ```json
   {
     "timestamp": "2026-03-13T12:00:00Z",
     "level": "info",
     "message": "Agent run started",
     "trace_id": "abc-123",
     "span_id": "def-456",
     "agent": "dba-optimizer",
     "run_id": "run-789",
     "fields": {"iterations": 5}
   }
   ```

5. **SpanRecord Attributes** — Document common attributes attached to spans:
   - LLM call spans: model, provider, input_tokens, output_tokens, cost_usd
   - Tool call spans: tool_name, tool_type, duration_ms
   - Run spans: total_iterations, total_tool_calls, final_status

6. **CLI Access** — Preview of `agentix logs <agent> --trace` (implemented in Plan 18-05).
