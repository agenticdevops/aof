**Create `crates/agentix-runtime/src/telemetry.rs`:**

```rust
use std::collections::HashMap;
use std::sync::Arc;
use parking_lot::Mutex;
use agentix_core::telemetry::{
    LogLevel, SpanKind, SpanRecord, SpanStatus, StructuredLogEntry, TraceContext,
};

/// Collects trace spans and structured log entries during an agent run.
///
/// Thread-safe via `Arc<Mutex<_>>` so it can be shared with async tasks.
/// The collector holds all spans and logs for one agent run, identified by
/// a single TraceContext (one trace_id).
#[derive(Debug, Clone)]
pub struct TraceCollector {
    inner: Arc<Mutex<TraceCollectorInner>>,
}

#[derive(Debug)]
struct TraceCollectorInner {
    trace_context: TraceContext,
    spans: Vec<SpanRecord>,
    logs: Vec<StructuredLogEntry>,
}
```

Methods:

`TraceCollector::new(trace_context: TraceContext) -> Self` — wraps inner in Arc<Mutex>.

`TraceCollector::record_span(&self, span: SpanRecord)` — pushes span into inner.spans.

`TraceCollector::log(&self, level: LogLevel, message: &str, fields: HashMap<String, serde_json::Value>)` — creates a StructuredLogEntry using the trace_context's trace_id, span_id, agent_name, run_id, and pushes into inner.logs.

`TraceCollector::get_spans(&self) -> Vec<SpanRecord>` — returns cloned span list.

`TraceCollector::get_logs(&self) -> Vec<StructuredLogEntry>` — returns cloned log list.

`TraceCollector::trace_context(&self) -> TraceContext` — returns a clone of the trace context.

`TraceCollector::start_span(&self, name: &str, kind: SpanKind) -> SpanRecord` — delegates to inner trace_context.child_span().

Add `pub mod telemetry;` to `crates/agentix-runtime/src/lib.rs` and re-export:
`pub use telemetry::TraceCollector;`

Modify `ReActEngine` to accept and populate a `TraceCollector` during run execution.

**Add optional TraceCollector field to ReActEngine:**
```rust
pub struct ReActEngine {
    model: Arc<dyn agentix_core::Model + Send + Sync>,
    tool_executor: Arc<dyn ToolExecutor>,
    config: ReActConfig,
    event_tx: Option<broadcast::Sender<ReActEvent>>,
    trace_collector: Option<TraceCollector>,  // NEW
}
```

**Add builder method:**
```rust
pub fn with_trace_collector(mut self, collector: TraceCollector) -> Self {
    self.trace_collector = Some(collector);
    self
}
```

**Instrument ReActEngine::run():**

At the start of `run()`:
- If trace_collector is Some, create a root Run span: `let mut run_span = collector.start_span("agent_run", SpanKind::Run);`
- Add attributes: `run_span = run_span.with_attribute("agent", &definition.name);`
- Log: `collector.log(Info, "Agent run started", {("input_length", input.len())})`

Before memory recall:
- If trace_collector is Some and vector_memory enabled, create MemoryRecall span, complete it after recall finishes.

Before research phase:
- If trace_collector is Some and research_phase enabled, create Research span, complete it after research finishes.

Inside the loop, for each iteration:
- Create an Iteration span: `collector.start_span(&format!("iteration_{}", iteration), SpanKind::Iteration)` with attribute `iteration_number`.

Before `self.model.generate()`:
- Create an LlmCall span. After the response is received, set attributes: model (from definition), input_tokens (from response.usage), output_tokens. Then complete the span.

For each tool dispatch:
- Create a ToolCall span with attribute `tool_name`. After dispatch, set attribute `status` = "ok" or "error". Complete the span.

After the iteration completes:
- Set attribute `tool_count` = number of tool calls in this iteration. Complete the Iteration span.

At the end of `run()` (in all return paths: final answer, max iterations, token budget exceeded):
- Set run_span attributes: `total_iterations`, `total_tool_calls`, `total_input_tokens`, `total_output_tokens`.
- Complete the run_span (with error if the run failed).
- Record the run_span via `collector.record_span(run_span)`.

IMPORTANT: All trace instrumentation must be guarded by `if let Some(ref collector) = self.trace_collector { ... }` to ensure zero-cost when tracing is not enabled. The existing behavior of the ReAct loop must not change.
