Create `crates/agentix-runtime/src/trace_store.rs` modeled on `cost_store.rs`. Use `rusqlite` with `parking_lot::Mutex` for the connection.

**Schema (in TraceStore::open):**
```sql
CREATE TABLE IF NOT EXISTS spans (
    span_id         TEXT PRIMARY KEY,
    parent_span_id  TEXT,
    trace_id        TEXT NOT NULL,
    run_id          TEXT NOT NULL,
    agent_name      TEXT NOT NULL,
    name            TEXT NOT NULL,
    kind            TEXT NOT NULL,
    start_time      TEXT NOT NULL,
    end_time        TEXT,
    duration_ms     INTEGER,
    status          TEXT NOT NULL DEFAULT 'ok',
    status_message  TEXT,
    attributes      TEXT NOT NULL DEFAULT '{}'
);
CREATE INDEX IF NOT EXISTS idx_spans_trace ON spans(trace_id);
CREATE INDEX IF NOT EXISTS idx_spans_run   ON spans(run_id);

CREATE TABLE IF NOT EXISTS structured_logs (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp   TEXT NOT NULL,
    level       TEXT NOT NULL,
    message     TEXT NOT NULL,
    trace_id    TEXT,
    span_id     TEXT,
    agent       TEXT,
    run_id      TEXT,
    fields      TEXT NOT NULL DEFAULT '{}'
);
CREATE INDEX IF NOT EXISTS idx_logs_run    ON structured_logs(run_id);
CREATE INDEX IF NOT EXISTS idx_logs_trace  ON structured_logs(trace_id);
```

**impl TraceStore:**

`open(path: &str) -> Result<Self, AgentixError>` — same pattern as CostStore::open.

`insert_spans(&self, spans: &[SpanRecord], agent_name: &str, run_id: &str) -> Result<(), AgentixError>` — INSERT each span. Serialize attributes as JSON string. Map SpanStatus::Ok to status="ok"/status_message=NULL, SpanStatus::Error(msg) to status="error"/status_message=msg. Serialize SpanKind via serde.

`insert_logs(&self, logs: &[StructuredLogEntry]) -> Result<(), AgentixError>` — INSERT each log entry. Serialize fields as JSON string.

`get_trace(&self, trace_id: &str) -> Result<Vec<SpanRecord>, AgentixError>` — SELECT all spans WHERE trace_id=?1, reconstruct SpanRecord from columns.

`get_run_trace(&self, run_id: &str) -> Result<Vec<SpanRecord>, AgentixError>` — SELECT all spans WHERE run_id=?1 ORDER BY start_time ASC.

`get_run_logs(&self, run_id: &str) -> Result<Vec<StructuredLogEntry>, AgentixError>` — SELECT all logs WHERE run_id=?1 ORDER BY timestamp ASC.

Add `pub mod trace_store;` to `crates/agentix-runtime/src/lib.rs` and re-export:
`pub use trace_store::TraceStore;`

Add two new REST API endpoints to the gateway router:

**GET /api/v1/agents/:name/runs/:run_id/trace**

Returns the span tree for a run as a JSON array of span objects, ordered by start_time:
```json
[
  {
    "span_id": "...",
    "parent_span_id": null,
    "trace_id": "...",
    "name": "agent_run",
    "kind": "run",
    "start_time": "2026-03-13T12:00:00Z",
    "end_time": "2026-03-13T12:00:05Z",
    "duration_ms": 5000,
    "status": "ok",
    "attributes": {"agent": "dba-optimizer", "total_iterations": "3"}
  },
  ...
]
```

Handler `get_run_trace`:
- Call `manager.trace_store.get_run_trace(&run_id)`.
- Map each SpanRecord to a JSON value.
- Return 200 with the array, or 404 if no spans found.

**GET /api/v1/agents/:name/runs/:run_id/structured-logs**

Returns structured log entries for a run as a JSON array:
```json
[
  {
    "timestamp": "2026-03-13T12:00:00Z",
    "level": "info",
    "message": "Agent run started",
    "trace_id": "abc-123",
    "span_id": "def-456",
    "agent": "dba-optimizer",
    "run_id": "run-789",
    "fields": {"input_length": 42}
  },
  ...
]
```

Handler `get_run_structured_logs`:
- Call `manager.trace_store.get_run_logs(&run_id)`.
- Serialize and return.

**Update router registration:**
- Add `.route("/api/v1/agents/:name/runs/:run_id/trace", get(get_run_trace))`
- Add `.route("/api/v1/agents/:name/runs/:run_id/structured-logs", get(get_run_structured_logs))`

**Update API doc comment** at the top of api.rs to include the new endpoints in the table.
