/// Telemetry configuration for workspace-level observability settings.
///
/// ```yaml
/// spec:
///   telemetry:
///     enabled: true
///     otlp_endpoint: "http://localhost:4318/v1/traces"
///     service_name: "my-workspace"
///     export_metrics: true
/// ```
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TelemetryConfig {
    /// Whether telemetry collection is enabled (default: true).
    #[serde(default = "default_true")]
    pub enabled: bool,
    /// OTLP HTTP endpoint for span export (e.g., "http://localhost:4318/v1/traces").
    /// When set, spans are pushed to this endpoint after each agent run.
    #[serde(skip_serializing_if = "Option::is_none")]
    pub otlp_endpoint: Option<String>,
    /// Service name reported in OTel resource attributes (default: "agentix").
    #[serde(default = "default_service_name")]
    pub service_name: Option<String>,
    /// Whether to export Prometheus metrics at /metrics (default: true).
    #[serde(default = "default_true")]
    pub export_metrics: bool,
}

fn default_true() -> bool { true }
fn default_service_name() -> Option<String> { Some("agentix".to_string()) }
```

**Methods:**

`OtelExporter::new(config: TelemetryConfig) -> Self` — stores config, creates reqwest::Client.

`OtelExporter::export_spans(service_name: &str, spans: &[SpanRecord]) -> serde_json::Value` — static method. Converts spans to OTLP v1 JSON format:
```json
{
  "resourceSpans": [{
    "resource": {
      "attributes": [
        {"key": "service.name", "value": {"stringValue": "<service_name>"}}
      ]
    },
    "scopeSpans": [{
      "scope": {"name": "agentix", "version": "<crate version>"},
      "spans": [
        {
          "traceId": "<hex trace_id>",
          "spanId": "<hex span_id>",
          "parentSpanId": "<hex or empty>",
          "name": "<span name>",
          "kind": 1,
          "startTimeUnixNano": "<epoch nanos>",
          "endTimeUnixNano": "<epoch nanos>",
          "status": {"code": 1},
          "attributes": [...]
        }
      ]
    }]
  }]
}
```

Note: OTLP uses hex-encoded 16-byte trace IDs and 8-byte span IDs. Since our span_ids are UUIDs (32 hex chars), use the first 16 chars for span_id and first 32 chars for trace_id (pad/truncate as needed). Map SpanKind to OTLP kind integers (Run/Iteration→INTERNAL=1, LlmCall→CLIENT=3, ToolCall→CLIENT=3, Research→INTERNAL=1, MemoryRecall→INTERNAL=1). Map SpanStatus::Ok to code=1 (OK), SpanStatus::Error to code=2 (ERROR).

Convert SpanRecord attributes to OTLP attribute format:
```json
{"key": "model", "value": {"stringValue": "anthropic/claude-sonnet-4-6"}}
```

`OtelExporter::push_to_collector(&self, spans: &[SpanRecord]) -> Result<(), AgentixError>` — if config.otlp_endpoint is Some, POST the OTLP JSON to the endpoint. Log warning on failure, don't propagate error. Use reqwest with 5-second timeout.
