```rust
    pub reason: String,
}
impl fmt::Display for SsrfViolation { ... }
impl std::error::Error for SsrfViolation {}
```

**SsrfGuard:**
```rust
#[derive(Debug, Clone)]
pub struct SsrfGuard {
    pub allowed_private_endpoints: Vec<String>,
}
```

`SsrfGuard::default()` — empty allowed_private_endpoints.

`SsrfGuard::with_allowed(endpoints: Vec<String>) -> Self` — constructor with allow-list.

`SsrfGuard::check_url(&self, url: &str) -> Result<(), SsrfViolation>` — Parse the URL to extract the host. Resolve the hostname to an IP if needed. Check against blocked ranges:
- 127.0.0.0/8 (loopback)
- ::1 (IPv6 loopback)
- "localhost" hostname
- 10.0.0.0/8 (RFC 1918)
- 172.16.0.0/12 (RFC 1918)
- 192.168.0.0/16 (RFC 1918)
- 169.254.0.0/16 (link-local, cloud metadata)

Before blocking, check if the resolved IP matches any entry in `allowed_private_endpoints`. If it does, allow it.

Use `std::net::IpAddr` for IP parsing. For "localhost", map to 127.0.0.1. For URLs with hostnames that cannot be resolved at compile time, check the literal hostname against known patterns.

**SecurityConfig:**
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SecurityConfig {
    #[serde(default = "default_true")]
    pub ssrf_protection: bool,
    #[serde(default = "default_true")]
    pub secret_encryption: bool,
    #[serde(default = "default_true")]
    pub audit_enabled: bool,
    #[serde(default)]
    pub allowed_private_endpoints: Vec<String>,
}
```

Default: all true, empty allow-list.

```rust
    pub denied_capabilities: Vec<String>,
}
```
