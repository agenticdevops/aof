**SecretStore:**
```rust
pub struct SecretStore {
    key: [u8; 32], // AES-256 key derived from passphrase via SHA-256
}
```

`SecretStore::new(passphrase: &str) -> Self` — derive key using SHA-256 of the passphrase bytes.

`SecretStore::encrypt(&self, plaintext: &str) -> Result<EncryptedSecret, SecretError>` — Generate a random 12-byte nonce using `aes_gcm::aead::OsRng`. Encrypt using AES-256-GCM. Return EncryptedSecret with ciphertext, nonce, and created_at=Utc::now().

`SecretStore::decrypt(&self, encrypted: &EncryptedSecret) -> Result<String, SecretError>` — Decrypt using AES-256-GCM with the stored key and the encrypted secret's nonce. Convert decrypted bytes to UTF-8 string.

**SecretRedactor:**

pub struct SecretRedactor {

}

`SecretRedactor::new(secrets: Vec<(String, String)>) -> Self`

`SecretRedactor::redact(&self, text: &str) -> String` — Replace all occurrences of each secret value with `[REDACTED:<name>]`. Process secrets in order of longest value first to avoid partial matches.

`SecretRedactor::redact_json(&self, value: &serde_json::Value) -> serde_json::Value` — Recursively walk the JSON tree. For string values, apply `redact()`. For objects and arrays, recurse. Return the redacted copy.
