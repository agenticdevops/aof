**Types:**

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AuditEntry {
    pub id: Option<i64>,
    pub timestamp: chrono::DateTime<chrono::Utc>,
    pub event_type: AuditEventType,
    pub agent_name: String,
    pub run_id: Option<String>,
    pub actor: String,           // "system", "agent:<name>", "user:<id>"
    pub action: String,          // description of what happened
    pub outcome: AuditOutcome,
    pub details: HashMap<String, serde_json::Value>,
    pub trace_id: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum AuditEventType {
    ToolCall,
    LlmCall,
    ApprovalDecision,
    AgentStart,
    AgentComplete,
    AgentError,
    SecurityViolation,
    SecretAccess,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum AuditOutcome {
    Success,
    Failure(String),
    Denied(String),
    Blocked(String),
}
```

**Schema (in AuditStore::open):**
```sql
CREATE TABLE IF NOT EXISTS audit_log (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp   TEXT NOT NULL,
    event_type  TEXT NOT NULL,
    agent_name  TEXT NOT NULL,
    run_id      TEXT,
    actor       TEXT NOT NULL,
    action      TEXT NOT NULL,
    outcome     TEXT NOT NULL,
    outcome_msg TEXT,
    details     TEXT NOT NULL DEFAULT '{}',
    trace_id    TEXT
);
CREATE INDEX IF NOT EXISTS idx_audit_agent ON audit_log(agent_name);
CREATE INDEX IF NOT EXISTS idx_audit_run   ON audit_log(run_id);
CREATE INDEX IF NOT EXISTS idx_audit_type  ON audit_log(event_type);
CREATE INDEX IF NOT EXISTS idx_audit_time  ON audit_log(timestamp);
```

**impl AuditStore:**

`open(path: &str) -> Result<Self, AgentixError>` — same pattern as CostStore::open.

`log_event(&self, entry: AuditEntry) -> Result<(), AgentixError>` — INSERT the entry. Map AuditOutcome::Success to outcome="success"/outcome_msg=NULL, AuditOutcome::Failure(msg) to outcome="failure"/outcome_msg=msg, etc.

`get_agent_audit(&self, agent_name: &str, limit: u32) -> Result<Vec<AuditEntry>, AgentixError>` — SELECT WHERE agent_name=?1 ORDER BY timestamp DESC LIMIT ?2.

`get_run_audit(&self, run_id: &str) -> Result<Vec<AuditEntry>, AgentixError>` — SELECT WHERE run_id=?1 ORDER BY timestamp ASC.

`get_security_events(&self, limit: u32) -> Result<Vec<AuditEntry>, AgentixError>` — SELECT WHERE event_type IN ('security_violation') OR outcome IN ('denied', 'blocked') ORDER BY timestamp DESC LIMIT ?1.

Add `pub mod audit_store;` to `crates/agentix-runtime/src/lib.rs` and re-export:
`pub use audit_store::{AuditStore, AuditEntry, AuditEventType, AuditOutcome};`

Add two new REST API endpoints to the gateway router:

**GET /api/v1/agents/:name/audit**

Returns audit entries for an agent as a JSON array, most recent first. Accepts optional `?limit=N` query parameter (default: 100).

```json
[
  {
    "id": 42,
    "timestamp": "2026-03-13T12:00:05Z",
    "event_type": "tool_call",
    "agent_name": "dba-optimizer",
    "run_id": "run-789",
    "actor": "agent:dba-optimizer",
    "action": "Executed tool: kubectl get pods -n production",
    "outcome": "success",
    "details": {"tool_name": "kubectl", "duration_ms": 150},
    "trace_id": "abc-123"
  },
  ...
]
```

Handler `get_agent_audit`:
- Extract `name` from path, `limit` from query (default 100).
- Call `manager.audit_store().get_agent_audit(&name, limit)`.
- Return 200 with JSON array.

**GET /api/v1/audit/security**

Returns security-relevant audit events (violations, denials, blocks). Accepts optional `?limit=N` (default: 50).

Handler `get_security_audit`:
- Call `manager.audit_store().get_security_events(limit)`.
- Return 200 with JSON array.

**Update router registration:**
- Add `.route("/api/v1/agents/:name/audit", get(get_agent_audit))`
- Add `.route("/api/v1/audit/security", get(get_security_audit))`

**Update API doc comment** at the top of api.rs to include the new endpoints in the table.

Run `cargo check --workspace`.
