**ApprovalStatus:**
```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(tag = "status", rename_all = "snake_case")]
pub enum ApprovalStatus {
    Pending,
    Approved {
        approver: String,
        decided_at: DateTime<Utc>,
    },
    Denied {
        approver: String,
        reason: Option<String>,
        decided_at: DateTime<Utc>,
    },
    TimedOut {
        expired_at: DateTime<Utc>,
    },
}
```

**ApprovalRequest:**
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ApprovalRequest {
    pub id: String,
    pub run_id: String,
    pub agent_name: String,
    pub action_description: String,
    pub tool_name: Option<String>,
    pub tool_input: Option<serde_json::Value>,
    pub requested_at: DateTime<Utc>,
    pub timeout_secs: u32,
    pub status: ApprovalStatus,
}
```

`ApprovalRequest::new(run_id, agent_name, action_description, tool_name, tool_input, timeout_secs)` — generates UUID id, sets status=Pending, requested_at=Utc::now().

`ApprovalRequest::approve(&mut self, approver: &str) -> Result<(), String>` — if Pending, transitions to Approved. Otherwise returns Err("already decided").

`ApprovalRequest::deny(&mut self, approver: &str, reason: Option<String>) -> Result<(), String>` — if Pending, transitions to Denied. Otherwise returns Err("already decided").

`ApprovalRequest::is_expired(&self) -> bool` — returns true if status is Pending and Utc::now() > requested_at + Duration::seconds(timeout_secs).

**ApprovalDecision:**

Create `docs/concepts/approval-workflows.md` covering:

1. **Overview** — OpenAgentiX supports human-in-the-loop approval workflows, allowing organizations to maintain control over agent actions in production environments. Agents can operate in three autonomy modes, with configurable approval gates for specific tools or action patterns.

2. **Autonomy Modes** — Document the three modes from AgentMode:
   - `autonomous` — Agent executes all actions without human approval (default)
   - `semi-autonomous` — Agent pauses and requests approval for flagged tools/patterns
   - `manual` — Agent requests approval for every tool call
   - Example agent.yaml showing mode configuration

3. **Approval Policy** — Document how to configure which actions require approval:
   - `flagged_tools` — List of tool names that always require approval in semi-autonomous mode
   - `flagged_patterns` — Regex/substring patterns matched against tool inputs
   - `approvers` — List of authorized approver identities
   - `default_timeout_secs` — How long before an unanswered approval request times out
   - Example configuration:
     ```yaml
     approval:
       mode: semi-autonomous
       flagged_tools:
         - kubectl
         - aws
       flagged_patterns:
         - delete
         - drop
         - terminate
       approvers:
         - "slack:U015ADMIN"
         - "email:sre-lead@company.com"
       timeout_seconds: 300
     ```

4. **Approval Flow** — Document the request lifecycle:
   - Agent encounters a flagged action during the ReAct loop
   - Agent pauses and creates an ApprovalRequest (Pending)
   - Notification sent to configured approvers (CLI, Slack, etc.)
   - Approver reviews and approves (`agentix approve <run-id>`) or denies (`agentix deny <run-id>`)
   - Agent resumes (approved) or skips the action and reports denial (denied)
   - Request times out if no response within timeout period
   - All decisions logged in audit trail

5. **CLI Commands** — Preview of approval CLI:
   - `agentix approve <run-id>` — Approve the pending action for a run
   - `agentix deny <run-id> --reason "Too risky"` — Deny the pending action
   - `agentix approvals` — List all pending approval requests
   - `agentix approvals --agent <name>` — List pending approvals for an agent

6. **Audit Integration** — All approval decisions are logged in the audit trail with:
   - Approver identity
   - Decision timestamp
   - Approval or denial (with reason)
   - The action that was approved/denied
   - Run and agent context

7. **Configuration Reference** — Full YAML reference for approval settings in agent.yaml and agentix.yaml.
