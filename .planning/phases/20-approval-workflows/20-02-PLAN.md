**ApprovalStore:**
```rust
pub struct ApprovalStore {
    conn: Arc<Mutex<Connection>>,
}
```

Schema:
```sql
CREATE TABLE IF NOT EXISTS approval_requests (
    id              TEXT PRIMARY KEY,
    run_id          TEXT NOT NULL,
    agent_name      TEXT NOT NULL,
    action_description TEXT NOT NULL,
    tool_name       TEXT,
    tool_input      TEXT,
    requested_at    TEXT NOT NULL,
    timeout_secs    INTEGER NOT NULL,
    status          TEXT NOT NULL DEFAULT 'pending',
    status_data     TEXT NOT NULL DEFAULT '{}'
);
CREATE INDEX IF NOT EXISTS idx_approval_run ON approval_requests(run_id);
CREATE INDEX IF NOT EXISTS idx_approval_agent ON approval_requests(agent_name);
CREATE INDEX IF NOT EXISTS idx_approval_status ON approval_requests(status);
```

The `status` column stores "pending", "approved", "denied", or "timed_out".
The `status_data` column stores a JSON object with the variant-specific fields (approver, reason, decided_at, expired_at).

Methods:
- `open(path: &str) -> Result<Self, AgentixError>` — open/create DB with WAL mode
- `create_request(request: &ApprovalRequest) -> Result<(), AgentixError>` — INSERT
- `get_request(request_id: &str) -> Result<Option<ApprovalRequest>, AgentixError>` — SELECT by id
- `get_pending_by_run(run_id: &str) -> Result<Vec<ApprovalRequest>, AgentixError>` — SELECT WHERE run_id AND status='pending'
- `get_pending_by_agent(agent_name: &str) -> Result<Vec<ApprovalRequest>, AgentixError>` — SELECT WHERE agent_name AND status='pending'
- `list_pending(limit: u32) -> Result<Vec<ApprovalRequest>, AgentixError>` — SELECT WHERE status='pending' ORDER BY requested_at DESC LIMIT
- `update_status(request_id: &str, new_status: &ApprovalStatus) -> Result<(), AgentixError>` — UPDATE status and status_data
- `expire_timed_out() -> Result<u32, AgentixError>` — UPDATE all rows WHERE status='pending' AND (requested_at + timeout_secs) < now. Returns count of affected rows.

Add `pub mod approval_store;` to `crates/agentix-runtime/src/lib.rs` and re-export `ApprovalStore`.
