Create `crates/agentix/src/commands/approve.rs` with two handler functions:

**approve_request(ctx, request_id):**
- POST to `{gateway_url}/api/v1/approvals/{request_id}/approve` with `{ "approver": "cli-user" }`
- On 200: print "Approved: {request_id}" (text) or emit JSON response
- On 404: print "Approval request not found: {request_id}"
- On 409: print "Request already decided: {request_id}"
- On other errors: print error

**deny_request(ctx, request_id, reason):**
- POST to `{gateway_url}/api/v1/approvals/{request_id}/deny` with `{ "approver": "cli-user", "reason": reason }`
- Same response handling as approve

Add to cli.rs:
```rust
/// Approve a pending agent action
Approve {
    /// Approval request ID
    request_id: String,
},
/// Deny a pending agent action
Deny {
    /// Approval request ID
    request_id: String,
    /// Reason for denial
    #[arg(long, short)]
    reason: Option<String>,
},
```

Wire in main.rs:
```rust
Commands::Approve { request_id } => {
    commands::approve::approve_request(&ctx, &request_id).await
}
Commands::Deny { request_id, reason } => {
    commands::approve::deny_request(&ctx, &request_id, reason.as_deref()).await
}
```

## v2.0.0-alpha.8 — Approval Workflows

### Added
- **Approval workflows** — Human-in-the-loop approval gates for agent actions (APPR-01 through APPR-05)
- Three autonomy modes: `autonomous`, `semi-autonomous`, `manual`
- `ApprovalPolicy` — configurable flagged tools and patterns for semi-autonomous mode
- `ApprovalStore` — SQLite-backed approval request persistence
- ReAct loop approval gate — pauses before flagged actions, polls for approval decision
- REST API: `GET/POST /api/v1/approvals` endpoints for managing approval queue
- CLI: `agentix approve`, `agentix deny`, `agentix approvals` commands
- Background task for automatic expiration of unanswered approval requests
- Approval decisions logged in audit trail
- Quickstart: `semi-autonomous-agent` example with kubectl approval gates
- Docs: approval-workflows concept guide
