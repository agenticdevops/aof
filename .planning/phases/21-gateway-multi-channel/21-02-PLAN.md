**ChannelGateway trait implementation:**
- `send_message(channel_id, text, thread_id)` — POST to `https://slack.com/api/chat.postMessage` with JSON body `{ channel, text, thread_ts? }`, Authorization header `Bearer {bot_token}`
- `send_notification(target, payload)` — POST to `https://slack.com/api/chat.postMessage` with Block Kit formatted payload
- `platform_type()` — returns ChannelPlatformType::Slack

**Webhook parsing:**
- `parse_webhook(payload: &[u8], headers: &HashMap<String, String>) -> Result<Option<ChannelMessage>, AgentixError>`
- Handles url_verification (returns None)
- Handles event_callback with app_mention (returns Some(ChannelMessage))
- Ignores non-mention message events (returns None)

**Signature verification:**
- `verify_signature(payload: &[u8], signature: &str, timestamp: &str) -> bool`
- Computes HMAC-SHA256 of `v0:{timestamp}:{body}` using signing_secret
- Compares against provided `v0={hex}` signature

**Notification formatting:**
- `format_notification_blocks(payload: &NotificationPayload) -> serde_json::Value`
- Returns Slack Block Kit blocks with:
  - Header block: notification title
  - Section block: body text
  - Context block: agent name, run_id (if present), severity badge
  - Color-coded attachment based on severity
