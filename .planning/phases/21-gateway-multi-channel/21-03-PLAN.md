- Constructor must validate that credentials are ChannelCredentials::Telegram variant

**ChannelGateway trait implementation:**
- `send_message(channel_id, text, thread_id)` — POST to `{api_base}sendMessage` with JSON body `{ chat_id: channel_id, text, parse_mode: "MarkdownV2", reply_to_message_id: thread_id.map(parse_i64) }`
- `send_notification(target, payload)` — Format notification as Markdown text, POST via sendMessage
- `platform_type()` — returns ChannelPlatformType::Telegram

**Webhook parsing:**
- `parse_webhook(payload: &[u8], headers: &HashMap<String, String>) -> Result<Option<ChannelMessage>, AgentixError>`

- Return None if no message or no text
- Set thread_id from reply_to_message.message_id if present

- `verify_webhook_secret(headers: &HashMap<String, String>) -> bool`
- If self.webhook_secret is None, return true (no verification)
- Check "x-telegram-bot-api-secret-token" header against stored secret

**Notification formatting:**
- `format_notification_text(payload: &NotificationPayload) -> String`
- Format: `{severity_emoji} *{title}*\n{body}\n_{agent_name}_{optional_run_id}`
- Severity emojis: Info=ℹ️, Warning=⚠️, Error=❌, Critical=🚨
