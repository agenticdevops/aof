- Constructor must validate that credentials are ChannelCredentials::Discord variant

**ChannelGateway trait implementation:**
- `send_message(channel_id, text, thread_id)` — POST to `https://discord.com/api/v10/channels/{channel_id}/messages` with JSON body `{ content: text, message_reference: thread_id.map(|id| { message_id: id }) }`, Authorization header `Bot {bot_token}`
- `send_notification(target, payload)` — POST with embed-formatted payload
- `platform_type()` — returns ChannelPlatformType::Discord

**Webhook parsing:**
- `parse_webhook(payload: &[u8], _headers: &HashMap<String, String>) -> Result<Option<ChannelMessage>, AgentixError>`
- Check for interaction type 1 (PING) — return None (gateway handles pong)
- Check for gateway event type "MESSAGE_CREATE" with bot mention (`<@{application_id}>` in content)
- Ignore messages from bot authors (author.bot == true)
- Extract channel_id, author.id, author.username, content, message_reference.message_id
- Return ChannelMessage with platform=Discord

**Signature verification:**
- `verify_signature(payload: &[u8], signature: &str, timestamp: &str) -> bool`
- Verify Ed25519 signature using public_key against `{timestamp}{body}` message
- Port logic from crates/agentix-triggers/src/platforms/discord.rs

```json
    "timestamp": "ISO8601"
  }]
}
```
- Severity colors: Info=0x36a64f, Warning=0xffc107, Error=0xdc3545, Critical=0xff0000
