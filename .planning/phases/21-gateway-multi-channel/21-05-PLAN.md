```rust
pub struct ChannelGatewayManager {

    routes: Vec<(ChannelPlatformType, ChannelRoute)>,
}
```

- `new(configs: Vec<ChannelConfig>) -> Result<Self, AgentixError>`:
  - Filter out configs where enabled=false
  - For each remaining config, create the appropriate gateway (SlackChannelGateway, TelegramChannelGateway, DiscordChannelGateway) based on config.platform
  - Collect all routes with their platform type
  - If a platform appears twice, return error (one gateway per platform)

- `route_inbound(platform: ChannelPlatformType, channel_id: &str) -> Option<String>`:
  - Find first route matching platform + channel_id where matches_agent is possible (direction is Inbound or Bidirectional)
  - Return the agent_name

- `send_response(platform: ChannelPlatformType, channel_id: &str, text: &str, thread_id: Option<&str>) -> Result<(), AgentixError>`:
  - Look up gateway for platform
  - Call gateway.send_message(channel_id, text, thread_id)

- `send_notification(target: &NotificationTarget, payload: &NotificationPayload) -> Result<(), AgentixError>`:
  - Look up gateway for target.platform
  - Call gateway.send_notification(target, payload)

- `get_all_routes() -> Vec<ChannelRouteInfo>`:
  - Return all routes as ChannelRouteInfo

- `get_gateway(&self, platform: &ChannelPlatformType) -> Option<&dyn ChannelGateway>`:
  - Return reference to the gateway for a platform (used by webhook handler)

   ```rust
   let channel_manager = if let Some(ref ws) = workspace_config {
       if let Some(ref channels) = ws.spec.channels {
           match ChannelGatewayManager::new(channels.clone()) {
               Ok(mgr) => Some(mgr),
               Err(e) => {
                   eprintln!("Warning: failed to initialize channel gateway: {}", e);
                   None
               }
           }
       } else { None }
   } else { None };
   ```
3. Add accessor: `pub fn channel_manager(&self) -> Option<&ChannelGatewayManager>`
4. In run completion path: if agent has outbound routes configured, fire run-completion notification via channel_manager.send_notification()

**Update REST API** (`crates/agentix-runtime/src/gateway/api.rs`):

1. Add `GET /api/v1/channels` endpoint:
   - Handler: `list_channels`
   - Returns JSON array of ChannelRouteInfo from channel_manager.get_all_routes()
   - Returns empty array if no channel_manager

2. Add `POST /api/v1/notify` endpoint:
   - Handler: `send_notification`
   - Accepts JSON body: `{ platform: "slack", channel_id: "C123", agent_name: "...", title: "...", body: "...", severity: "info" }`
   - Constructs NotificationTarget + NotificationPayload
   - Calls channel_manager.send_notification()
   - Returns 200 on success, 404 if no channel_manager or platform not configured

3. Add `POST /webhooks/channels/:platform` endpoint:
   - Handler: `channel_webhook`
   - Extracts platform from path
   - Gets the appropriate ChannelGateway from channel_manager
   - Calls parse_webhook on the gateway
   - If returns Some(ChannelMessage):
     - Routes via route_inbound(platform, channel_message.channel_id)
     - If agent found: triggers a run with the message text as input
     - Waits for run completion (with a timeout)
     - Sends response back via send_response
   - If returns None: returns 200 OK (acknowledged but ignored)
   - For Slack url_verification: detect and return the challenge directly

4. Register new routes in `create_router`:
   ```rust
   .route("/api/v1/channels", get(list_channels))
   .route("/api/v1/notify", post(send_notification))
   .route("/webhooks/channels/:platform", post(channel_webhook))
   ```
