Create `crates/agentix/src/commands/channels.rs` with:

**list_channels(ctx):**
- GET `{gateway_url}/api/v1/channels`
- Text output: formatted table with columns: Platform, Channel ID, Agent, Direction, Description
- JSON output: raw JSON array from API
- If no channels configured: print "No channels configured"

**send_notify(ctx, platform, channel_id, title, body, severity):**
- POST `{gateway_url}/api/v1/notify` with JSON body:
  ```json
  {
    "platform": platform,
    "channel_id": channel_id,
    "agent_name": "cli",
    "title": title,
    "body": body,
    "severity": severity
  }
  ```
- On 200: print "Notification sent to {platform}:{channel_id}"
- On 404: print "Channel not configured or platform not available"
- On other errors: print error

Add to cli.rs:
```rust
/// List configured channel routes
Channels,
/// Send a notification to a channel
Notify {
    /// Target platform (slack, telegram, discord)
    #[arg(long)]
    platform: String,
    /// Target channel ID
    #[arg(long)]
    channel_id: String,
    /// Notification title
    #[arg(long)]
    title: String,
    /// Notification body
    #[arg(long)]
    body: String,
    /// Severity level (info, warning, error, critical)
    #[arg(long, default_value = "info")]
    severity: String,
},
```

Wire in main.rs:
```rust
Commands::Channels => {
    commands::channels::list_channels(&ctx).await
}
Commands::Notify { platform, channel_id, title, body, severity } => {
    commands::channels::send_notify(&ctx, &platform, &channel_id, &title, &body, &severity).await
}
```

Add `pub mod channels;` to commands/mod.rs.

**quickstart/agentix-channels.yaml** — Example workspace config with channels:
```yaml
apiVersion: openagentix.dev/v1
kind: Workspace
metadata:
  name: multi-channel-demo
spec:
  defaults:
    model: anthropic/claude-sonnet-4-6
  providers:
    anthropic:
      api_key: "${ANTHROPIC_API_KEY}"
  gateway:
    host: "0.0.0.0"
    port: 8080
  agents_dir: "./agents"
  channels:
    - platform: slack
      credentials:
        platform: slack
        bot_token: "${SLACK_BOT_TOKEN}"
        signing_secret: "${SLACK_SIGNING_SECRET}"
        app_id: "${SLACK_APP_ID}"
      routes:
        - channel_id: "${SLACK_CHANNEL_DEVOPS}"
          agent_name: devops-assistant
          direction: bidirectional
          description: "DevOps team channel — ask infrastructure questions"
        - channel_id: "${SLACK_CHANNEL_ALERTS}"
          agent_name: devops-assistant
          direction: outbound
          description: "Alerts channel — agent sends notifications here"
      enabled: true
    - platform: telegram
      credentials:
        platform: telegram
        bot_token: "${TELEGRAM_BOT_TOKEN}"
        webhook_secret: "${TELEGRAM_WEBHOOK_SECRET}"
      routes:
        - channel_id: "${TELEGRAM_CHAT_ID}"
          agent_name: devops-assistant
          direction: bidirectional
          description: "Telegram group for on-call team"
      enabled: true
```

## v2.0.0-alpha.9 — Multi-Channel Gateway

### Added
- **Multi-channel gateway** — Bi-directional communication with Slack, Telegram, and Discord (GW-01 through GW-06)
- `ChannelGateway` trait — Pluggable channel adapter interface in agentix-core
- `SlackChannelGateway` — Slack Events API webhooks + chat.postMessage responses + Block Kit notifications
- `TelegramChannelGateway` — Telegram Bot API webhooks + sendMessage responses + Markdown notifications
- `DiscordChannelGateway` — Discord gateway events + REST API responses + embed notifications
- `ChannelGatewayManager` — Routes inbound messages to agents, dispatches outbound notifications
- Per-channel agent routing via `channels:` in `agentix.yaml` workspace config
- Three routing modes: `inbound`, `outbound`, `bidirectional`
- Webhook signature verification: HMAC-SHA256 (Slack), secret token (Telegram), Ed25519 (Discord)
- Outbound notification system with severity levels (info, warning, error, critical)
- Platform-specific formatting: Slack Block Kit, Telegram Markdown, Discord embeds
- REST API: `GET /api/v1/channels`, `POST /api/v1/notify`, `POST /webhooks/channels/:platform`
- CLI: `agentix channels` (list routes), `agentix notify` (send notification)
- Quickstart: `agentix-channels.yaml` workspace + `slack-agent` example
- Docs: multi-channel gateway concept guide, channel config reference
