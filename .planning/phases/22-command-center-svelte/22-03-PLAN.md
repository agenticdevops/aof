  <name>Task 1: WebSocket store + agent/run stores with live updates</name>
  <files>
    apps/command-center/src/lib/stores/websocket.ts
    apps/command-center/src/lib/stores/agents.ts
  </files>
  <action>
    1. Create `src/lib/stores/websocket.ts`:
       - Export a `createWebSocket()` function that:
         - Reads `gatewayUrl` store, converts `http://` to `ws://` (or `https://` to `wss://`)
         - Connects to `${wsUrl}/ws`
         - Parses incoming JSON messages as `GatewayEvent` (matching the Rust enum's snake_case `type` field)
         - Distributes events to a Svelte readable store `wsEvents` (latest event)
         - Tracks connection state in a `wsStatus` store: 'connecting' | 'connected' | 'disconnected'
         - Auto-reconnects with exponential backoff (1s, 2s, 4s, max 30s) on disconnect
         - Provides `disconnect()` to tear down
       - Export: `wsEvents` (readable store of latest GatewayEvent), `wsStatus` (readable store of connection status), `initWebSocket()`, `disconnectWebSocket()`

    2. Create `src/lib/stores/agents.ts`:
       - Export a reactive store module:
         - `agents` writable store: `Agent[]` initially empty
         - `loadAgents()` async function: calls `api.agents.list()`, updates store
         - `selectedAgent` writable store: `Agent | null`
         - `loadAgent(name: string)` async function: calls `api.agents.get(name)`, updates selectedAgent
         - `agentRuns` writable store: `AgentRun[]`
         - `loadAgentRuns(name: string)` async function: calls `api.runs.listForAgent(name)`, updates agentRuns
         - Subscribe to `wsEvents` store: when an `agent_status` event arrives, update the matching agent in the `agents` list in-place (reactive). When a `run_completed` event arrives, reload runs if viewing that agent.

    3. Both stores must handle errors gracefully — set error state rather than crashing the UI. Use try/catch around all API calls, expose an `error` store or return error state.
  </action>

  </verify>
  <done>WebSocket store connects to gateway /ws, auto-reconnects, distributes typed events. Agent store fetches from REST and reacts to WebSocket events for live status updates. Zero type errors.</done>
