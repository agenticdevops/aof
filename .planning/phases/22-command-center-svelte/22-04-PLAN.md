  <action>
    1. Choose and install chart library. Use **Chart.js** with `svelte-chartjs` wrapper (Claude's discretion on chart library — Chart.js provides the best balance of beauty, interactivity, and Svelte compatibility. It supports bar, line, pie/doughnut with smooth animations, tooltips, and click handlers out of the box).
       - `cd apps/command-center && npm install chart.js svelte-chartjs`
       - Chart.js provides canvas-based rendering with GPU acceleration, smooth animations, and rich plugin ecosystem.

    2. Create `src/lib/utils/chart-helpers.ts`:
       - Export color palette function: `getAgentColor(index: number): string` — returns from a curated palette of 12 beautiful colors (slate blues, teals, purples, ambers — matching the slate aesthetic). Each color has a main and a lighter variant for hover.
       - Export `formatCurrency(usd: number): string` — formats as "$0.0023" or "$1.23" depending on magnitude.
       - Export `formatTokens(count: number): string` — formats as "1.2K" or "12.5M".
       - Export `aggregateCostsByDate(runs: RunCostDetail[]): { date: string; cost: number }[]` — groups run costs by date, returns daily aggregates sorted chronologically.
       - Export `aggregateCostsByAgent(summaries: CostSummary[]): { agent: string; cost: number; percentage: number }[]` — computes cost distribution percentages.

    3. Create `src/lib/stores/costs.ts`:
       - `costSummaries` writable store: `CostSummary[]`
       - `dateRange` writable store: `{ start: Date; end: Date }` initialized to last 30 days
       - `selectedAgent` writable store: `string | null` for drill-down
       - `agentRunCosts` writable store: `RunCostDetail[]` (populated on drill-down)
       - `loadCosts()` async: calls `api.costs.listAll()`, populates store
       - `loadAgentCosts(name: string)` async: calls `api.costs.getAgentRuns(name)`, populates agentRunCosts
       - `filteredRunCosts` derived store: filters agentRunCosts by dateRange
       - Error handling: try/catch, expose `costError` store

    4. Create `src/lib/components/date-range-picker.svelte`:
       - Two date inputs (start, end) styled with the app's Input component
       - Quick-select buttons: "7 days", "30 days", "90 days", "Year"
       - Emits `onchange` event with `{ start: Date, end: Date }`
       - Tailwind styling: inline flex layout, matches slate theme
  </action>

       - Animation: Line draws from left to right, 800ms ease-in-out

       - Animation: Segments animate in clockwise rotation, 700ms
