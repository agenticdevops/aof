  <action>
    1. Create `src/lib/utils/trace-helpers.ts`:

       **buildSpanTree(spans: SpanRecord[]): SpanNode[]**
       - Convert flat SpanRecord[] into a tree structure: `interface SpanNode { span: SpanRecord; children: SpanNode[]; depth: number; }`
       - Root spans have no parent_span_id. Children nest under their parent.
       - Sort children by start_time within each parent.
       - Return the root nodes array.

       **calculateTimeScale(spans: SpanRecord[]): TimeScale**
       - Find earliest start_time and latest end_time across all spans
       - Return `{ startMs: number; endMs: number; totalMs: number; }` for positioning bars on the waterfall

       **spanPosition(span: SpanRecord, scale: TimeScale): { leftPercent: number; widthPercent: number }**
       - Calculate the left offset and width of a span bar as percentages of total duration
       - Handle spans with no end_time (still running) — extend to current time or scale end

       **spanKindIcon(kind: SpanKind): string**
       - Map span kinds to Lucide icon names: run -> PlayCircle, iteration -> RotateCw, llm_call -> Brain, tool_call -> Wrench, research -> Search, memory_recall -> Database, approval_wait -> ShieldCheck

       **spanKindColor(kind: SpanKind): string**
       - Map span kinds to Tailwind color classes: llm_call -> 'bg-purple-500', tool_call -> 'bg-teal-500', iteration -> 'bg-blue-500', run -> 'bg-slate-500', research -> 'bg-amber-500', memory_recall -> 'bg-emerald-500', approval_wait -> 'bg-orange-500'

       **detectCoordination(spans: SpanRecord[]): CoordinationEdge[]**
       - Scan spans for delegation patterns: spans with kind='tool_call' and attributes containing 'delegate_to' or 'target_agent'
       - Return edges: `{ from: string; to: string; runId?: string }` for the coordination graph

    2. Create `src/lib/stores/traces.ts`:
       - `traceSpans` writable store: `SpanRecord[]`
       - `spanTree` derived store: computes `buildSpanTree(traceSpans)` reactively
       - `timeScale` derived store: computes `calculateTimeScale(traceSpans)` reactively
       - `coordinationEdges` derived store: computes `detectCoordination(traceSpans)`
       - `selectedSpan` writable store: `SpanRecord | null`
       - `loadTrace(agentName: string, runId: string)` async: calls API, populates traceSpans
       - Error handling with `traceError` store
