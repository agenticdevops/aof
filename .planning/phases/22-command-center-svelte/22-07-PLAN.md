apiVersion: openagentix.dev/v1

    1. Create `src/lib/stores/builder.ts`:
       - Define `AgentFormState` interface:
         ```typescript
         interface AgentFormState {
           name: string;
           namespace: string;
           version: string;
           modelPreferred: string;
           modelFallback: string;
           mode: 'manual' | 'semi-autonomous' | 'autonomous';
           skills: string[];
           tools: string[];
           triggers: TriggerFormItem[];
           budgetDailyLimit: string;  // string for form input, convert to number
           budgetMaxTokens: string;
           telemetryEnabled: boolean;
           soulMd: string;  // SOUL.md content
         }
         interface TriggerFormItem { type: string; expression?: string; channel?: string; }
         ```
       - `builderForm` writable store: `AgentFormState` with sensible defaults (mode: 'semi-autonomous', telemetryEnabled: true)
       - `builderErrors` writable store: `Record<string, string>` (field -> error message)
       - `validateForm()`: validates required fields (name required, name must be kebab-case, model required), returns boolean
       - `resetForm()`: resets to defaults
       - `testRunOutput` writable store: `string` (accumulated SSE output)
       - `testRunning` writable store: `boolean`

    2. Create `src/lib/utils/yaml-generator.ts`:
       - `generateAgentYaml(form: AgentFormState): string`: Converts form state to valid agent.yaml content. Output format:
         ```yaml
         apiVersion: openagentix.dev/v1
         kind: Agent
         metadata:
           name: {form.name}
           namespace: {form.namespace || 'default'}
           version: {form.version || '1.0.0'}
         spec:
           model:
             preferred: {form.modelPreferred}
             fallback: {form.modelFallback || omit}
           mode: {form.mode}
           skills: {form.skills}
           tools: {form.tools}
           triggers: {form.triggers mapped to YAML}
           budget:
             daily_limit: {parsed number or omit}
             max_tokens_per_run: {parsed number or omit}
           telemetry:
             enabled: {form.telemetryEnabled}
         ```
       - `parseAgentYaml(yaml: string): Partial<AgentFormState>`: Parse YAML back into form state (for editing existing agents). Use a simple YAML parser (install `yaml` npm package: `npm install yaml`).
       - Handle edge cases: omit empty/undefined fields, format numbers correctly

    3. Create `src/lib/components/agent-form.svelte`:
       - Props: binds to `builderForm` and `builderErrors` stores
       - Fields (grouped in sections with subtle dividers):
         - **Identity**: name (text input, kebab-case validation), namespace (text, default 'default'), version (text, default '1.0.0')
         - **Model**: preferred model (dropdown with common options: claude-sonnet-4-20250514, claude-haiku-35-20241022, gpt-4o, gpt-4o-mini), fallback model (same dropdown, optional)
         - **Mode**: radio buttons for manual/semi-autonomous/autonomous with descriptions
         - **Triggers**: dynamic list — add/remove trigger entries. Each trigger: type dropdown (cron, webhook, github, jira, slack, discord, telegram), expression field (shows for cron), channel field (shows for messaging types)
         - **Budget**: daily limit USD input, max tokens per run input (both optional)
         - **Telemetry**: toggle switch
       - Show inline validation errors from `builderErrors` below each field (red text)
       - Two-way binding: changes update the store immediately

    4. Create `src/lib/components/soul-editor.svelte`:
       - Props: `value: string` (bindable), `oninput: (value: string) => void`
       - Split view: left side = textarea (monospace, full height), right side = rendered markdown preview
       - Tab toggle: "Edit" | "Preview" | "Split" (default: Split on desktop, tabbed on mobile)
       - Toolbar above editor: Bold (B), Italic (I), Heading (H), Link, Code Block, List buttons
       - Toolbar buttons insert markdown syntax at cursor position
       - Textarea: styled with monospace font, line numbers (CSS counter or manual), comfortable line height
       - Preview: rendered HTML from markdown (use a simple markdown-to-HTML converter — install `marked` package: `npm install marked`)
       - Placeholder text: "Describe your agent's identity, expertise, and behavior..."

    5. Create `src/lib/components/yaml-preview.svelte`:
       - Props: `yaml: string`
       - Read-only code display with syntax highlighting (use a simple approach: wrap YAML in `<pre><code>` with Tailwind typography classes)
       - Copy button in top-right: copies YAML to clipboard
       - Monospace font, dark background regardless of theme (code block aesthetic)
       - Auto-updates as form changes (reactive from store)
