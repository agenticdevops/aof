```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum ProviderMode {
    Api,
    Subscription,
}

impl Default for ProviderMode {
    fn default() -> Self { Self::Api }
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct OAuthConfig {
    #[serde(skip_serializing_if = "Option::is_none")]
    pub client_id: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub client_secret: Option<String>,
}
```

```rust
pub struct ProviderConfig {

    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub oauth: Option<OAuthConfig>,
}
```

Create `crates/agentix-core/src/auth.rs` by adapting zeroclaw's auth modules into a single file (sub-modules can be added later by executors of plan 02). Port these components:

**From zeroclaw profiles.rs — adapt directly:**
- `AuthProfileKind` enum (OAuth, Token)
- `TokenSet` struct (access_token, refresh_token, id_token, expires_at, token_type, scope) with `is_expiring_within()` method
- `AuthProfile` struct (id, provider, profile_name, kind, account_id, workspace_id, token_set, token, metadata, created_at, updated_at) — use Debug impl that redacts secrets
- `AuthProfilesData` (schema_version, updated_at, active_profiles BTreeMap, profiles BTreeMap)
- `AuthProfilesStore` — encrypted JSON file store at `~/.agentix/auth-profiles.json`
  - Uses agentix-core's existing `SecretStore` for ChaCha20-Poly1305 encryption (NOT SQLite per CONTEXT.md)
  - File-level locking via `auth-profiles.lock` (50ms poll, 10s timeout)
  - Atomic writes via temp file + rename
  - Methods: `load()`, `upsert_profile()`, `remove_profile()`, `set_active_profile()`, `clear_active_profile()`, `update_profile()`
- `profile_id()` function: `"{provider}:{profile_name}"`
- `select_profile_id()` function: priority is explicit override > active profile > default > first profile for provider

**From zeroclaw oauth_common.rs — copy directly:**
- `PkceState` struct (code_verifier, code_challenge, state)
- `generate_pkce_state()` — random 64-byte verifier, SHA-256 S256 challenge
- `random_base64url()` — OsRng + base64url encoding
- `url_encode()` / `url_decode()` — RFC 3986 percent encoding
- `parse_query_params()` — BTreeMap from query string

**Adapt provider names:** Change "openai-codex" to "openai" since we're targeting the official auth.openai.com OAuth (per CONTEXT.md decision: standard OAuth2, NOT unofficial).

**Auth constants (from zeroclaw mod.rs):**
- OPENAI_REFRESH_SKEW_SECS: 90
- OPENAI_REFRESH_FAILURE_BACKOFF_SECS: 10
- OAUTH_REFRESH_MAX_ATTEMPTS: 3
- OAUTH_REFRESH_RETRY_BASE_DELAY_MS: 350

**In lib.rs:** Add `pub mod auth;` and re-export key types: `AuthProfile, AuthProfileKind, TokenSet, AuthProfilesStore, AuthProfilesData, PkceState`.

**Tests in auth_types_test.rs:**
- `profile_id_format` — verifies "{provider}:{name}" format
- `token_expiry_within` — TokenSet.is_expiring_within() returns true/false correctly
- `token_not_expiring_when_no_deadline` — None expires_at means not expiring
- `pkce_generation_is_valid` — verifier length >= 43, challenge non-empty
- `pkce_challenge_is_sha256_of_verifier` — verify S256 math
- `url_encode_decode_roundtrip` — encode then decode returns original
- `parse_query_params_basic` — extracts key=value pairs
- `select_profile_prefers_override_then_active_then_default` — tests priority chain
- `store_roundtrip_with_encryption` (async) — create store in tempdir, upsert profile, reload, verify tokens decrypt correctly AND raw file contains "enc2:" prefixed values (not plaintext)
- `atomic_write_replaces_file` (async) — verify file exists after upsert

**Important:** The `AuthProfilesStore` must use `crate::secret_store::SecretStore` for encryption — check the existing SecretStore API in `secret_store.rs` and adapt zeroclaw's encrypt_optional/decrypt_optional pattern to use it.
