**OpenAI OAuth (from zeroclaw openai_oauth.rs):**
- Constants: `OPENAI_OAUTH_CLIENT_ID = "app_EMoamEEZ73f0CkXaXp7hrann"`, authorize URL `https://auth.openai.com/oauth/authorize`, token URL `https://auth.openai.com/oauth/token`, device code URL, redirect URI `http://localhost:1455/auth/callback`
- `build_authorize_url(pkce: &PkceState) -> String` — builds URL with response_type=code, client_id, redirect_uri, scope="openid profile email offline_access", code_challenge, code_challenge_method=S256, state
- `exchange_code_for_tokens(client, code, pkce) -> Result<TokenSet>` — POST to token URL with grant_type=authorization_code, code, client_id, redirect_uri, code_verifier
- `refresh_access_token(client, refresh_token) -> Result<TokenSet>` — POST with grant_type=refresh_token
- `start_device_code_flow(client) -> Result<DeviceCodeStart>` — for headless environments
- `poll_device_code_tokens(client, device) -> Result<TokenSet>` — polls with interval, handles authorization_pending/slow_down/access_denied/expired_token
- `receive_loopback_code(expected_state, timeout) -> Result<String>` — binds to 127.0.0.1:1455, reads HTTP request, extracts code from query params, validates state, returns success HTML page (change "ZeroClaw" to "OpenAgentiX")
- `parse_code_from_redirect(input, expected_state) -> Result<String>` — extracts code from URL, validates state
- `extract_account_id_from_jwt(token) -> Option<String>` — decodes JWT payload, looks for account_id/sub fields

**Gemini OAuth (from zeroclaw gemini_oauth.rs):**
- Constants: authorize URL `https://accounts.google.com/o/oauth2/v2/auth`, token URL `https://oauth2.googleapis.com/token`, device code URL, redirect URI `http://localhost:1456/auth/callback`, scopes `openid profile email https://www.googleapis.com/auth/cloud-platform`
- Client credentials from env: `GEMINI_OAUTH_CLIENT_ID`, `GEMINI_OAUTH_CLIENT_SECRET`
- `build_authorize_url(pkce, client_id) -> String` — includes access_type=offline, prompt=consent
- `exchange_code_for_tokens(client, code, pkce, client_id, client_secret) -> Result<TokenSet>`
- `refresh_access_token(client, refresh_token) -> Result<TokenSet>` — needs client_id + client_secret for Google
- `start_device_code_flow(client, client_id) -> Result<DeviceCodeStart>`
- `poll_device_code_tokens(client, device, client_id, client_secret) -> Result<TokenSet>`
- `receive_loopback_code(expected_state, timeout) -> Result<String>` — binds to 127.0.0.1:1456
- `extract_account_email_from_id_token(id_token) -> Option<String>` — JWT decode for email

**Anthropic Auth (from zeroclaw anthropic_token.rs):**
- `AnthropicAuthKind` enum (ApiKey, Authorization)
- `detect_auth_kind(token, explicit_override) -> AnthropicAuthKind` — JWT-like (2+ dots) = Authorization, sk-ant-api prefix = ApiKey, default = ApiKey
- `AnthropicAuthKind::as_metadata_value()` / `from_metadata_value()`
