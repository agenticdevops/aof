Create `commands/auth.rs` following the kubectl-style pattern established in other commands.

**Command structure:**
```
agentix auth start <provider>    # Initiate OAuth flow (opens browser)
agentix auth status              # Show auth status for all providers
agentix auth disconnect <provider>  # Remove stored credentials
```

**`agentix auth start <provider>`:**
1. Normalize provider name
2. For OpenAI:
   a. Generate PKCE state
   b. Build authorize URL
   c. Print: "Opening browser for OpenAI authentication..."
   d. Open URL in browser via `open` (macOS) / `xdg-open` (Linux) command
   e. Start loopback listener on 127.0.0.1:1455
   f. Wait for callback (5 min timeout)
   g. Exchange code for tokens
   h. Store tokens via AuthService
   i. Print: "OpenAI authentication successful! Account: {account_id}"
   j. On error: Print error, suggest device code flow

3. For Gemini:
   a. Check GEMINI_OAUTH_CLIENT_ID and GEMINI_OAUTH_CLIENT_SECRET env vars
   b. If missing, print clear error: "Set GEMINI_OAUTH_CLIENT_ID and GEMINI_OAUTH_CLIENT_SECRET environment variables"
   c. Generate PKCE state, build authorize URL
   d. Open browser, start loopback on 127.0.0.1:1456
   e. Exchange code, store tokens
   f. Print: "Gemini authentication successful! Account: {email}"

4. For Anthropic:
   a. Print: "Paste your Anthropic token (from `claude setup-token` or an API key):"
   b. Read token from stdin
   c. Detect auth kind (JWT = Bearer, sk-ant-api = API key)
   d. Store via AuthService
   e. Print: "Anthropic authentication saved (mode: {bearer|api-key})"

**Device code flow fallback** (for headless environments):
If the `--device-code` flag is passed (or browser open fails), use device code flow:
- OpenAI: `start_device_code_flow()` → print user_code and verification_uri → `poll_device_code_tokens()` → store
- Gemini: same pattern via `start_device_code_flow()`

**`agentix auth status`:**
1. Load all profiles from AuthService
2. For each of the three providers (anthropic, openai, gemini):
   - Find active profile
   - Print status table:
   ```
   Provider    Status          Mode     Account          Expires
   ----------  --------------  -------  ---------------  ----------
   Anthropic   Connected       token    -                Never
   OpenAI      Connected       oauth    acct_abc123      23h 15m
   Gemini      Not connected   -        -                -
   ```
3. If no profiles at all, print: "No providers authenticated. Run `agentix auth start <provider>` to get started."

**`agentix auth disconnect <provider>`:**
1. Normalize provider name
2. Remove profile via AuthService
3. Print: "Disconnected from {provider}."
4. If profile didn't exist, print: "No {provider} credentials found."

**Registration in mod.rs:** Add `pub mod auth;` and register in the subcommand list.

**Registration in cli.rs:** Add the `auth` subcommand with its sub-subcommands following the existing pattern.

**AuthService creation:** The CLI creates an AuthService with state_dir = `~/.agentix/` (using dirs::home_dir or equivalent) and encrypt_secrets = true.
