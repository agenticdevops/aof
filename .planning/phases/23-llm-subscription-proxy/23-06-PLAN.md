2. In client.ts, add the auth API methods:

```typescript
auth: {
    start(provider: string): Promise<AuthStartResponse> {
        return request<AuthStartResponse>('GET', `/api/v1/auth/${encodeURIComponent(provider)}/start`);
    },
    status(provider: string): Promise<AuthStatus> {
        return request<AuthStatus>('GET', `/api/v1/auth/${encodeURIComponent(provider)}/status`);
    },
    async disconnect(provider: string): Promise<void> {
        await del(`/api/v1/auth/${encodeURIComponent(provider)}`);
    },
    submitToken(provider: string, token: string): Promise<void> {
        return request<void>('POST', `/api/v1/auth/${encodeURIComponent(provider)}/token`, { token });
    }
},
```

Import AuthStatus and AuthStartResponse in the client imports.

**State additions:**
- `providerModes: Record<string, 'api' | 'subscription'>` — per-provider mode selection
- `authStatuses: Record<string, AuthStatus>` — per-provider auth status from API
- `authLoading: Record<string, boolean>` — loading state during OAuth flows
- `anthropicToken: string` — token input for Anthropic paste flow

**On mount:** For each provider, fetch auth status via `api.auth.status(provider.id)`. If authenticated, set mode to 'subscription'. Otherwise check if API key is configured and set to 'api'. If neither, no default (let user choose).

**Provider card layout — per CONTEXT.md wireframe:**
Each provider card gets:
- Header with provider label and segmented control (API Key | Subscription) as two buttons in a rounded pill
- API Key mode: show existing key input and save button (keep as-is from current implementation)
- Subscription mode, not connected: for OpenAI/Gemini show "Authorize with {Provider}" button; for Anthropic show token paste input with instructions "Paste your token from `claude setup-token` or enter an API key"
- Subscription mode, connected: green dot + "Connected" + optional account_id + optional "expires in Xh Ym" + Re-authorize and Disconnect buttons

**Helper functions:**

`startAuth(providerId)` — call api.auth.start(), if auth_url returned open popup via window.open('url', 'agentix-auth', 'width=600,height=700'), poll api.auth.status() every 2 seconds until authenticated=true, then close popup and update state. Timeout after 5 minutes.

`disconnectAuth(providerId)` — call api.auth.disconnect(), reset authStatuses entry to not-authenticated.

`submitAnthropicToken()` — call api.auth.submitToken('anthropic', token), clear input, refresh status.

`formatRelativeTime(isoDate)` — calculate remaining time from now to expiry, return "in Xh Ym" or "expired".

**Design notes (Claude's discretion per CONTEXT.md):**
- Auth status badge: green dot + "Connected" for authenticated, no dot + "Not connected" otherwise
- Loading states: "Authorizing..." with spinner during OAuth flow
- Error messages: "Authorization failed. Please try again." for generic errors
- Provider card layout: stack vertically, segmented control top-right of card header

**First-run wizard update:** If the wizard component exists (likely in +page.svelte or a separate component), update step 2 to show both API Key and Subscription options at the same level. The wizard should NOT default to API key — present both choices equally per CONTEXT.md.
