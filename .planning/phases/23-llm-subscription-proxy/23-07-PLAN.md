**docs/features/subscription-proxy.md:**
Feature overview document covering:
- What it is: Use existing LLM subscriptions instead of API keys
- Supported providers: Anthropic (Claude Pro/Max), OpenAI (ChatGPT Plus), Google (Gemini Advanced)
- How it works: OAuth-based authentication, encrypted token storage, transparent to agents
- Configuration: agentix.yaml provider mode settings
- Architecture: ProviderMode enum, AuthService, subscription adapters implementing Model trait
- Security: ChaCha20-Poly1305 encrypted token storage, per-profile async locking, no plaintext on disk
- Limitations: Token refresh may fail if subscription expires, no auto-fallback to API key
- Error handling: What happens when tokens expire, rate limits, etc.

**docs/reference/cli-auth.md:**
CLI reference for the `agentix auth` command:
```
agentix auth start <provider>     — Start OAuth flow (opens browser)
agentix auth start <provider> --device-code  — Headless device code flow
agentix auth status               — Show auth status for all providers
agentix auth disconnect <provider> — Remove stored credentials
```
Include examples for each provider:
- `agentix auth start openai` — Browser-based OAuth
- `agentix auth start gemini` — Requires GEMINI_OAUTH_CLIENT_ID + GEMINI_OAUTH_CLIENT_SECRET
- `agentix auth start anthropic` — Token paste from `claude setup-token`

**docs/tutorials/subscription-setup.md:**
Step-by-step tutorial for first-time setup:
1. Choose your provider
2. Set up authentication (with screenshots/terminal output examples)
3. Configure agentix.yaml for subscription mode
4. Verify with `agentix auth status`
5. Run an agent — it uses your subscription transparently

1. **CHANGELOG.md** — Add v2.0.0-alpha.11 entry at the top:

```markdown
## v2.0.0-alpha.11 (2026-03-22)

### Features — LLM Subscription Proxy (Phase 23)

- **Subscription authentication**: Use existing LLM subscriptions (Claude Pro/Max, ChatGPT Plus, Gemini Advanced) via OAuth instead of separate API keys
- **OAuth flows**: Browser-based PKCE flows for OpenAI and Google; token paste for Anthropic
- **CLI auth command**: `agentix auth start|status|disconnect` for managing provider credentials
- **Encrypted token storage**: OAuth tokens stored in ChaCha20-Poly1305 encrypted JSON profiles at `~/.agentix/auth-profiles.json`
- **Subscription provider adapters**: Transparent Model trait implementations — agents are unaware of API key vs subscription
- **ProviderMode configuration**: `mode: subscription` in agentix.yaml provider config
- **Command Center settings**: Segmented control per provider (API Key | Subscription) with OAuth popup flow
- **Device code flow**: `--device-code` flag for headless environments
- **Token refresh**: Automatic with 3 retries, exponential backoff, per-profile async locking

### Supported Providers

| Provider | Auth Method | Endpoint |
|----------|-------------|----------|
| OpenAI | OAuth2 PKCE via auth.openai.com | Official API (api.openai.com) |
| Google Gemini | OAuth2 PKCE via accounts.google.com | Generative Language API |
| Anthropic | Token paste (setup-token / API key) | Official Messages API |
```
