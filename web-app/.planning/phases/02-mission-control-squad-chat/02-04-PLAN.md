<objective>
Implement a comprehensive persona system so agents visually express their personality through colors, fonts, and icons. Each agent type (analyst, coordinator, specialist, responder) has a distinct visual identity that carries through all UI components. Users can optionally customize persona appearance.

**Purpose:** Make agents feel like distinct team members with unique personalities, not generic AI assistants. Visual branding creates emotional connection and memorability.

**Output:**
- Persona type definitions (agent types, colors, icons, fonts)
- Color palette system for each agent type (light/dark mode)
- AgentAvatar component with consistent persona styling
- Updated AgentCard and MessageCard to use persona colors
- Persona Redux slice for management
- Utility functions for persona styling lookups
- Optional customization UI (color picker for personas)
</objective>
